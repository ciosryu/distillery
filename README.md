# Distillery Tycoon

종합 주류 경영 시뮬레이션 (월 단위 턴제 타이쿤, 개인 프로젝트)

> 최종 목표는 **Godot로 만드는 PC(Steam)용 도트(픽셀) 그래픽 게임**입니다. 지금은 게임 설계 단계이며, 이 저장소의 TypeScript 시뮬레이션은 **설계 실험실·기준 구현**, 웹 화면은 수치를 검증하는 **프로토타입**입니다 (PRD §13.1).

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 시뮬레이션 단위 테스트
npm run balance    # 헤드리스 밸런스 시뮬레이션 — 전략별 비교 (기본 12시드 × 120개월)
npm run build      # 타입 검사 + 프로덕션 빌드
```

## 현재 범위 — Phase 1 샌드박스 MVP (한국) + Phase 1.5

| 시스템 | 내용 |
|---|---|
| 시간 | 1턴 = 1개월. 1개월 / 분기 / 1년 진행. 생산 지시는 바꿀 때까지 매달 반복 |
| 생산 | 증류식 소주·진·몰트 위스키 레시피(원재료 배합, 효모, 발효 기간, 증류 횟수, 컷 포인트, 상압/감압, 보태니컬) |
| 설비 | 단식(양파·랜턴·웜텁)·하이브리드·감압 증류기, 스테인리스·옹기 발효조, 숙성고 증설 — 설치 기간 있음 |
| 숙성 | 캐스크 3종(ex-버번 배럴·올로로소 벗·한국 참나무 쿼터), 크기·기온에 따른 숙성 속도, 습도에 따른 도수 변화, 재사용·재탄화 |
| 병입 | LPA 가중 블렌딩, 숙성 연수 = 최저 연수, 위스키(36개월·40%)·진(주니퍼 지배) 표기 규칙, 도수·병·칠 필터·패키징 |
| 시장 | 한국 기본 수요(`data/market/base-demand.json`) × 인지도 × 유통 커버리지 × 매력도 × 가격 탄력성, 주세(종가세 72% + 교육세) |
| 마진 구조 | 마진 사다리 — 진·저가 상품은 병당 고정비·유통비·낮은 가격 결정권으로 마진이 얇고(약 20%), 숙성 위스키는 두껍다(약 78%) |
| 원액 B2B | 몰트·그레인 원액을 블렌디드 위스키 회사·브로커에 현물 벌크 또는 정기 공급 계약(선급·위약금·신뢰도)으로 판매. 국내 블렌더는 국산 원액 프리미엄(+25%) |
| 그레인·블렌디드 | 연속식 증류기로 그레인 원액 대량 생산, 몰트+그레인 = 블렌디드 위스키, 대량 구매 할인 |
| 변동 요소 | 이벤트 33종(시장 국면·원가 충격·재해·규제·B2B·기회·사람), 예보(빗나갈 수 있음), 선택 이벤트, 기간 한정 보정치, 원재료 시세 랜덤 워크 |
| 재무·HR | 급여·관리비·유지비·마케팅, 대출 3종(거치 기간), 직원 3직군(디스틸러·숙성고 매니저·영업)·레벨업, 원액 브로커(NDP) |
| 저장 | 브라우저 localStorage 자동 저장 |

### 밸런스 기준선 (`npm run balance`, 20시드 × 120개월, 변동 요소 포함)

| 전략 | 파산 | 10년차 순자산 평균 | 시드별 1위 |
|---|---|---|---|
| 브랜드형 — 생산분 전량 숙성·병입 | 0/20 | 약 2.7억 | 1회 |
| 혼합형 — 몰트 생산을 늘리고 일부만 계약 | 1/20 | 약 7.5억 | 9회 |
| 확장형 — 몰트 증설분을 B2B로 | 2/20 | 약 0.1억 | 0회 |
| 그레인 공급형 — 연속식 증류기로 국내 블렌더에 대량 공급 | 9/20 | 약 12.2억 (생존 시) | 10회 |

- 한 전략이 60% 이상 1위면 지배 전략으로 보고 조정합니다. 지금은 최다 50%로, 고위험·고수익(그레인)과 안정형(혼합)이 갈립니다
- 수치는 모두 `[튜닝]` 대상입니다. 한국 진 시장 규모는 데이터 공백이라 임시 추정치를 씁니다(PRD §15-8)

## 구조

```
src/sim/      순수 TypeScript 시뮬레이션 코어 (React 의존 없음)
  content/    콘텐츠 데이터 (향미 축, 원재료·설비·캐스크, 주종 스키마, 한국 지역)
  step.ts     advanceMonth(state) — 월간 처리
  actions.ts  applyAction(state, action) — 플레이어 행동
src/store/    Zustand 스토어 (시뮬레이션 래핑 + 저장)
src/ui/       React + Tailwind 화면
scripts/      밸런스 시뮬레이션, 수요 데이터 빌더
```
