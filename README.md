# Distillery Tycoon

종합 주류 경영 시뮬레이션 (월 단위 턴제 타이쿤, 개인 프로젝트)

> 최종 목표는 **Godot로 만드는 PC(Steam)용 도트(픽셀) 그래픽 게임**입니다. 지금은 게임 설계 단계이며, 이 저장소의 TypeScript 시뮬레이션은 **설계 실험실·기준 구현**, 웹 화면은 수치를 검증하는 **프로토타입**입니다 (PRD §13.1).

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 시뮬레이션 단위 테스트
npm run balance    # 헤드리스 밸런스 시뮬레이션 — 전략별 비교 (기본 12시드 × 120개월, 한국)
npm run balance -- 20 120 all jeju # 시드수 개월수 전략 산지(gyeonggi·andong·jeju·kanto·kansai·hokkaido·yilan) 또는 국가(KR | JP | TW → 표준 산지)
npm run build      # 타입 검사 + 프로덕션 빌드
```

## 현재 범위 — Phase 1 샌드박스 MVP + Phase 1.5 + Phase 1.6 + Phase 1.7 (한국·일본·대만, 산지 7곳)

| 시스템 | 내용 |
|---|---|
| 국가·산지 | **국가**(세제·시장·생산 가능 주종·B2B) / **산지**(기후·물·원료 단가·물류·관리비·고유 이벤트·생산 상한) 2단 구조. 새 게임에서 산지 7곳 선택: 한국 경기·안동·제주 / 일본 간토·오사카교토·홋카이도 / 대만 이란 ([regions.md](docs/design/regions.md)) |
| 산지 대표 결정 | 숙성 재고 보유 비용(첫 36개월 면제), 경기 대형 유통 납품, 제주 면세 전용 한정판, 간토 위탁생산, 직판장(오사카·교토 관광객 최다)·미즈나라 프리미엄, 재고 담보대출(홋카이도 담보 비율 최고), 대만 24개월 위스키·수집가 매입 |
| 산지 특성 | 엔젤스 셰어 보정(이란 연 약 10%), 물(연수·화산암반수), 안동 전통주 주세 감면·온라인 직판(안동 쌀 원료만, 월 800kg 한도, 감면 구간 게임 규모), 원료 원산지(지역/국산/수입), 제주 지정면세점·지하수 취수 허가, 겨울 난방·발효 지연, 부지 개량(내진·온도 제어), 산지 한정 원료·설비(제주 차조, 홋카이도 감자, 석탄 직화 증류기), 산지 이벤트 |
| 시간 | 1턴 = 1개월. 1개월 / 분기 / 1년 진행. 생산 지시는 바꿀 때까지 매달 반복 |
| 생산 | 증류식 소주(한국)·본격 쇼추(일본)·고량주(한국)·진·몰트·그레인 위스키 레시피(원재료 배합, 효모, 발효 기간, 증류 횟수, 컷 포인트, 상압/감압, 보태니컬) |
| 설비 | 단식(양파·랜턴·웜텁)·하이브리드·감압 증류기, 스테인리스·옹기 발효조, 숙성고 증설 — 설치 기간 있음 |
| 숙성 | 캐스크 4종(ex-버번 배럴·올로로소 벗·한국 참나무 쿼터·미즈나라 혹스헤드), 크기·기온에 따른 숙성 속도, 습도에 따른 도수 변화, 재사용·재탄화 |
| 병입 | LPA 가중 블렌딩, 숙성 연수 = 최저 연수, 위스키(36개월·40%)·진(주니퍼 지배) 표기 규칙, 도수·병·칠 필터·패키징 |
| 시장 | 지역 기본 수요(`data/market/base-demand.json`) × 인지도 × 유통 커버리지 × 점유 상한 × 매력도 × 가격 탄력성. 한국 종가세 72%(**기준판매비율** 차감 후 과세) + 교육세 — 대신 수입 경쟁 기준가·높은 가격 민감도로 국산 마진은 얇다, 일본·대만 종량세 |
| 마진 구조 | 마진 사다리 — 진·저가 상품은 병당 고정비·유통비·낮은 가격 결정권으로 마진이 얇고(약 20%), 숙성 위스키는 두껍다(약 78%) |
| 원액 B2B | 몰트·그레인 원액을 블렌디드 위스키 회사·브로커에 현물 벌크 또는 정기 공급 계약(선급·위약금·신뢰도)으로 판매. 국산 원액 프리미엄(한국 +25%·일본 +35%·대만 +10%). 독립 병입자의 우수 캐스크 매입 제안 |
| 실존 이름 | 원액 구매자·독립 병입자·품평회·평론가 실명(`src/sim/content/names.ts`). 가상명 스위치, 부정적 이벤트는 가상 회사만, 인물 발언은 만들지 않음 (PRD §11.1) |
| 그레인·블렌디드 | 연속식 증류기로 그레인 원액 대량 생산, 몰트+그레인 = 블렌디드 위스키, 대량 구매 할인 |
| 변동 요소 | 이벤트 45종(공통 + 국가·산지 한정: 지진·쇼추 붐·원액 부족, 대만 거품 붕괴·수집 열풍, 해안 산지 태풍, 안동 탈춤축제, 제주 관광, 간사이 인바운드, 홋카이도 폭설 등), 예보(빗나갈 수 있음), 선택 이벤트, 기간 한정 보정치, 원재료 시세 랜덤 워크 |
| 재무·HR | 급여·관리비·유지비·마케팅, 대출 3종(거치 기간), 직원 3직군(디스틸러·숙성고 매니저·영업)·레벨업, 원액 브로커(NDP) |
| 저장 | 브라우저 localStorage 자동 저장 |

### 밸런스 기준선

`npm run balance -- 20 120 all <산지>` — 20시드 × 120개월, 변동 요소 포함. 칸 = 파산 수 · 10년차 순자산 평균 (한국: 기준판매비율 + 고세율 시장 보정)

| 산지 | 브랜드형 | 혼합형 | 확장형 | 그레인형 | 시드별 1위 (20시드) | 첫 흑자(브랜드형) |
|---|---|---|---|---|---|---|
| 경기 ★2 | 0 · 11.9억 | 0 · 7.1억 | 0 · 0.6억 | 8 · 4.7억 | **브랜드 18** · 혼합 1 · 그레인 1 ❌ | 9개월 |
| 안동 ★2 | 0 · **15.8억** | 0 · 12.2억 | 0 · 1.4억 | 0 · 7.2억 | **브랜드 19** · 혼합 1 ❌ | 7개월 |
| 제주 ★3 | 0 · 9.3억 | 0 · 4.6억 | 1 · −1.2억 | **20** · — | **브랜드 19** · 혼합 1 ❌ | 7개월 |
| 간토 ★3 | 2 · 14.2억 | 0 · 14.9억 | 1 · 4.6억 | 5 · 10.4억 | **혼합 13** · 브랜드 5 · 그레인 2 ❌ | 25개월 |
| 오사카·교토 ★3 | 2 · 13.6억 | 1 · 14.2억 | 2 · 3.7억 | 5 · 9.1억 | **혼합 13** · 브랜드 6 · 그레인 1 ❌ | 25개월 |
| 홋카이도 ★4 | 4 · 14.3억 | 3 · 16.3억 | 1 · 3.8억 | 7 · 9.2억 | **혼합 14** · 브랜드 2 · 확장 1 · 그레인 2 · 전멸 1 ❌ | 34개월 |
| 이란 ★3 | 0 · 9.1억 | 0 · 10.7억 | 0 · 4.2억 | 2 · 7.8억 | **혼합 14** · 브랜드 4 · 그레인 2 ❌ | 17개월 |

- 전략: 브랜드형(생산분 전량 숙성·병입) · 혼합형(같은 생산량, 일부 계약 + 오래된 캐스크 현물 판매) · 확장형(48개월 후 증설분 B2B) · 그레인형(연속식 증류기 + 자사 블렌디드). 모든 전략이 공백기에 매입 원액을 병입한다
- 나라별 최적 전략은 갈리지만(한국 브랜드 / 일본·대만 혼합), **7개 산지 모두 한 전략이 60% 이상 1위 → 지배 전략 기준 미달.** 비교 실험(기준판매비율 켬, 전통주 특례 끔 등)과 해석은 [regions.md §6.1](docs/design/regions.md)
- **v0.8 산지 대표 결정(#65) 이후** 산지 전용 전략(site)과 숙성 재고 보유 비용이 추가됐다 — 1위 집계는 1위의 95% 이내를 공동 1위로 나눈다(#67). **7개 산지 중 4곳(경기·간토·오사카교토·이란)이 60% 기준 통과**, 미달은 안동·제주·홋카이도. 위 표는 그 이전 4전략 기준이며, site 전략 포함 결과는 [regions.md §6.2.1](docs/design/regions.md)
- 수치는 모두 `[튜닝]`. 일본·대만 시장 규모·세율 일부와 산지 기후는 추정치

## 구조

```
src/sim/      순수 TypeScript 시뮬레이션 코어 (React 의존 없음)
  content/    콘텐츠 데이터 (향미 축, 원재료·설비·캐스크, 주종 스키마, 국가(regions.ts)·산지(sites.ts), 이벤트, 실존 이름(names.ts))
  sites.ts    산지 규칙 — 부지 개량, 전통주 감면, 취수 허가, 계절, 테루아
  step.ts     advanceMonth(state) — 월간 처리
  actions.ts  applyAction(state, action) — 플레이어 행동
src/store/    Zustand 스토어 (시뮬레이션 래핑 + 저장)
src/ui/       React + Tailwind 화면
scripts/      밸런스 시뮬레이션, 수요 데이터 빌더
```
