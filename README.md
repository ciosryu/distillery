# Distillery Tycoon

종합 주류 경영 시뮬레이션 (월 단위 턴제 타이쿤, 개인 프로젝트)

> 최종 목표는 **Godot로 만드는 PC(Steam)용 도트(픽셀) 그래픽 게임**입니다. 지금은 게임 설계 단계이며, 이 저장소의 TypeScript 시뮬레이션은 **설계 실험실·기준 구현**, 웹 화면은 수치를 검증하는 **프로토타입**입니다 (PRD §13.1).

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 시뮬레이션 단위 테스트
npm run balance    # 헤드리스 밸런스 시뮬레이션 — 전략별 비교 (기본 12시드 × 120개월, 한국)
npm run balance -- 20 120 all JP   # 시드수 개월수 전략 지역(KR | JP | TW)
npm run build      # 타입 검사 + 프로덕션 빌드
npm run bench      # 틱 성능 측정 — 캐스크 수별 월 처리·복제·세이브 크기 (npm run bench -- 250 1000 5000)
```

## 현재 범위 — Phase 1 샌드박스 MVP + Phase 1.5~1.7 + v1.0 운영 시스템 (한국·일본·대만)

| 시스템 | 내용 |
|---|---|
| 지역 | 새 게임에서 **한국·일본·대만** 선택, 지역 안의 **입지**(한국 경기·안동·제주, 일본 간토·오사카교토·홋카이도, 대만 이란·진먼섬) 선택 — 입지마다 물·관리비·땅값·물류·관광과 대표 결정(경기 대형 유통 납품, 제주 면세 한정판, 간토 위탁생산, 홋카이도 재고 담보대출)이 다르다(v1.5 #86~#91, [regions.md](docs/design/regions.md)). 지역마다 기후·세제(종가세/종량세)·인건비·고정비·시장·생산 가능 주종·지역 보태니컬·이벤트 가중·매입 원액 감점·캐스크 가격이 다르다 |
| 시간 | 1턴 = 1개월. 1개월 / 분기 / 1년 진행. 생산 지시는 바꿀 때까지 매달 반복 |
| 생산 | 증류식 소주(한국)·본격 쇼추(일본)·고량주(한국·대만, 진먼섬 입지는 진먼 고량주 특산물)·진·몰트·그레인 위스키 레시피(원재료 배합, 효모, 발효 기간, 증류 횟수, 컷 포인트, 상압/감압, 보태니컬) |
| 설비 | 단식(양파·랜턴·웜텁)·하이브리드·감압 증류기, 스테인리스·옹기 발효조, 숙성고 증설 — 설치 기간 있음 |
| 숙성 | 캐스크 4종(ex-버번 배럴·올로로소 벗·한국 참나무 쿼터·미즈나라 혹스헤드), 크기·기온에 따른 숙성 속도, 습도에 따른 도수 변화, 재사용·재탄화, 캐스크 보관비·보험료. 증발(엔젤스 셰어) 연 약 2%(스코틀랜드형)·4.5~5%(한국·일본)·9.3~10.6%(대만) |
| 병입 | LPA 가중 블렌딩, 숙성 연수 = 최저 연수, **나라별 위스키 최소 숙성**(일본 규정 없음 → 즉시, 한국 1년, 대만 2년, 기본 3년)·재패니즈 위스키 표기(3년·자사 원액)·진(주니퍼 지배) 표기 규칙, 어린 위스키 인식 할인, 도수·병(375~700ml)·칠 필터·패키징 |
| 시장 | 지역 기본 수요(`data/market/base-demand.json`) × 인지도 × 유통 커버리지 × 점유 상한 × 매력도 × 가격 탄력성. 한국 종가세 72% + 교육세, 일본·대만 종량세 |
| 마진 구조 | 마진 사다리 — 진·저가 상품은 병당 고정비·유통비·낮은 가격 결정권으로 마진이 얇고(약 20%), 숙성 위스키는 두껍다(약 78%) |
| 원액 B2B | 몰트·그레인 원액을 블렌디드 위스키 회사·브로커에 현물 벌크 또는 정기 공급 계약(선급·위약금·신뢰도)으로 판매. 크래프트 프리미엄 계약(소량·고단가). 계약 숙성 영향 경고(납품 종료·첫 위스키와 겹치는 기간). 그레인 현물 시장 포화(대만). 국산 원액 프리미엄(한국 +25%·일본 +35%·대만 +10%). 독립 병입자의 우수 캐스크 매입 제안 |
| 매입 원액 | 브로커 숙성 원액 매입 → 병입. 브랜드 가치는 매입가로 결정(싼 원액 = 저가 하이볼용). 감점 계수 한국 0.4·대만 0.7·일본 0.85 |
| v1.0 운영 | 교차 생산(모든 지역 모든 주종, 원산지 잠금 제외)·물류 배수 · 발효실 온도(저온 플로럴·고온 열대 과일·산패) · 습도 숙성(습하면 도수↓·건조하면 도수↑) · 숙성고 공간(더니지 3단·랙 다단, 단별 내부 온도, QC 로테이션) · 소매 처리 역량·재고 적체 · 캐스크 시장(쿠퍼리지·스팟 골빈 통·시즈닝 계약·중고 매각) · HR 에이징 커브·마스터/부사수 하우스 스타일·QC 오염 색출·사무직 · 엔젤/VC 투자·캐스크 오너십·IB 통째 매각 · 재해 방재 설비·관세 보복·스페인 가뭄·짐 머레이·세무조사 · 비지터 센터 3등급·뉴메이크·입소문 오픈런 (PRD §16) |
| 실존 이름 | 원액 구매자·독립 병입자·품평회·평론가 실명(`src/sim/content/names.ts`). 가상명 스위치, 부정적 이벤트는 가상 회사만, 인물 발언은 만들지 않음 (PRD §11.1) |
| 그레인·블렌디드 | 연속식 증류기로 그레인 원액 대량 생산, 몰트+그레인 = 블렌디드 위스키, 대량 구매 할인 |
| 변동 요소 | 이벤트 39종(공통 + 지역 한정: 일본 지진·쇼추 붐·원액 부족, 대만 거품 붕괴·수집 열풍, 태풍 등), 예보(빗나갈 수 있음), 선택 이벤트, 기간 한정 보정치, 원재료 시세 랜덤 워크 |
| 재무·HR | 급여·관리비·유지비·마케팅, 대출 3종(거치 기간), 직원 3직군(디스틸러·숙성고 매니저·영업)·레벨업, 원액 브로커(NDP) |
| 저장 | 브라우저 localStorage 자동 저장 |

- 날씨 도입 전(v1.5)과의 비교·40시드 재측정은 PRD §16.25. 대만 이란은 통과로 바뀌었다. 한국 경기는 40시드에서 통과(site 53%), **제주 면세 한정판(site)은 날씨와 무관하게 v1.5부터 지배 전략(40시드 68~70%)** — 튜닝 과제

- 전략:
  - 브랜드형: 몰트 7배치 고정
  - 혼합형: 뉴메이크 계약을 적게(25%), 짧게(첫 위스키 전 종료)
  - 확장형: 60개월부터 수요가 공급의 1.3배를 넘으면 증류기를 늘려 자사 위스키로 숙성
  - 그레인형: 연속식 증류기로 그레인 원액 공급
- 봇의 위스키 병입량은 수요를 따른다(지난달 수요의 1.5개월치) → PRD §16.19
- 입지 대표 결정(site 열) — 경기 대형 유통·제주 면세 기념품·간토 위탁생산·오사카교토 미즈나라·홋카이도 재고 담보 → PRD §16.21·§16.24
- `DIAG=1 npm run balance -- …` — 판별 현금 흐름 진단 JSON을 stderr로 출력
- 수치는 모두 `[튜닝]` 대상

## 구조

```
src/sim/        순수 TypeScript 시뮬레이션 코어 (React 의존 없음)
  types.ts      GameState v6 — 헤더(시간·지역·시드) + 도메인 슬라이스(world·finance·hr·production·inventory·commerce·b2b·events·research·site·history)
  step.ts       advanceMonth — 월 틱 파이프라인 0~9단계 (PRD §2.2)
  tick.ts       틱 컨텍스트 — 칸(숙성고×단) 기후표·칸 점유·QC 스탯을 한 달에 한 번
  engine.ts     GameEngine 계약(명령 → 스냅샷), advanceUntil(멈춤 조건)
  actions.ts    applyAction — 플레이어 행동 (입구에서 isUnlocked)
  migrate.ts    세이브 마이그레이션 체인 (v5 → v6)
  weather.ts    기상 이상치 AR(1)·이벤트 충격
  lifecycle.ts  제품 아카이브·연 요약
  blendRadar.ts 블렌딩 레이더 미니게임 코어
  content/      콘텐츠 데이터 (향미 축, 원재료·설비·캐스크, 주종 스키마, 지역, 이벤트, 테크 노드, 실존 이름)
src/store/      Zustand — 엔진 스냅샷 읽기 모델(game.ts) + 비영속 UI 상태(ui.ts) + 셀렉터 + 세이브(persist.ts)
src/ui/         React + Tailwind 화면
scripts/        밸런스 시뮬레이션, 틱 벤치마크, 수요 데이터 빌더, 코드모드
```
