- 함의: #311(수출 1.0)은 **증산 전략의 상한을 크게 낮춘다.** 생산량 지배 전략의 강도는 약해진다(STATUS 「생산량」). 그래도 새 v16에서 증산 X13F(49.99억)는 X0(28.26억)보다 +21.7억이다 → **증산이 여전히 지배적인지가 40시드 안건이다**(C-2 · C-8 함께).
