## 읽기 (MGT — 판정 아님)
1. **조건 2는 standard에서 통과, micro는 6배치가 비김이다.**
   - standard: 수출이 잠긴 v16에서 증산 이득이 수출 있던 때보다 5.6억(6배치)·9.6억(8배치) 작다. #311의 「국내 천장」이 의도대로 묶인다.
   - micro: 수출 잠금의 비용 자체가 거의 없다. 수출 순효과가 +0.4~1.4억이다.
     - 그래서 잠김과 해제의 증산 이득이 거의 같고, 천장이 묶이지 않는다.
     - micro는 원액 잉여가 작아 수출할 몫이 애초에 없기 때문이다 `[추론 — 수출 매출 29~34억이 모두 국내 판매에서 옮겨 온 몫(못 판 국내 수요 ×4)]`.
2. **원액 잉여가 없는 판에서 수출은 새 매출이 아니라 국내 판매를 옮긴 것이다.**
   - standard 4배치와 micro 전 규모에서 수출 매출은 28~34억이다. 그런데 못 판 국내 수요가 약 6.5천 → 2.4만 병으로 늘고, 순자산은 비긴다.
   - 원인 `[사실 — 코드]`: `market.ts runSales` 1-b는 재고가 모자라면 **병당 순수입이 높은 판로부터** 채운다. 봇 수출가가 ×1.25라 수출이 먼저 채워진다.
3. **수출을 풀면 납품이 밀려난다. 납품을 켠 판은 해제가 오히려 손해다.**
   - 봇 규칙 짝에서 6칸 중 3칸 짐, 2칸 비김, 이김은 standard 8배치 1칸뿐이다.
   - 납품 계약이 4.4~6.5건에서 1.3~4.3건으로 준다. 납품 제안은 재고가 있는 범주에서 뽑는데(MKT), 수출이 재고를 먼저 가져가기 때문이다.
   - 함의: **1.0 수출을 다시 열 때(#311) 「높은 순수입 판로 먼저」 배분이 계약(납품) 판로를 굶기는지 같이 설계해야 한다** `[제안 — 1.0 몫, 지금 바꿀 것 아님]`. 사람도 수출가를 올리면 같은 일을 겪는다.
4. **잠긴 v16에서 납품이 수출 빈자리를 메운다.** standard 6배치는 사실상 전부(수출 순효과 5.75억 대 납품 이득 5.61억, 98%), 8배치는 64%를 메운다. 수출이 없는 MVP·v16에서 증산 판의 판로는 납품이 받친다.
5. **증산은 여전히 크다(조건 2와 별개).** standard 납품 끔 8배치 − 4배치가 +17.8억으로, 4배치 순자산(23.6억)의 75%다. 조건 2는 "수출 있을 때보다 작은가"만 묻는다. 그래서 통과가 곧 「증산이 지배하지 않는다」는 뜻은 아니다. 증산 지배 여부는 블록 A(위약금 P)와 함께 BAL이 본다.

## 반론 · 한계
- **봇 정책 의존:** 수출가 ×1.25와 「받을 수 있는 수출 제안은 받는다」는 봇 규칙이다. 수출가를 국내와 같게 두는 사람이라면 배분 순서가 달라 4배치 손해가 줄 것이다 `[추측]`.
- **수출 해제는 게임에 없는 반사실이다**(#311). 크기를 목표로 삼지 않는다.
- 180개월만 쟀다. 240개월은 조건 1·3 결과를 본 뒤 정한다(P-MGT-53 §7).
- 블록 B(전문가)는 이 폴더에 없다. MKT 본판으로 판독한다.
