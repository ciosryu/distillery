## 읽기 (MGT — 판정 아님)
1. **#525 머지 판단 기준(파산·급변): 파산 0.** 다만 **수출이 빠졌는데 순자산이 내려가지 않고 올라갔다** — X0W − 기준선 X0 = +0.28 · +0.82 · **+3.73 · +5.23억**(240개월에서 크다). 매출은 국내로 옮겨 갔다(standard 240: 국내 62.93 + 수출 49.78억 → 국내 102.49 + 수출 0억).
   - **수출 잠금 단독 효과는 마이너스다:** main `0a11e92`에서 X1(X0N − 수출) − X0N = **−3.94억(standard 240) · −3.36억(micro 240)**.
   - 그러니 #525의 **다른 변경이 240개월에서 순자산을 올린다.** 큰 몫은 **HR 잠금**으로 보인다. 옛 새 판은 120개월에 `y11_people`로 HR이 열렸고, 봇은 현금 10억↑이면 「연봉 협상」 사건을 받아들인다(`raiseIfCash`). main에서 X4(X0N − 연봉 인상) − X0N = **+5.24억(standard 240)**. #525 새 판은 HR이 잠겨 이 사건이 없다.
   - 셈: 수출 −3.94 + 연봉 인상 없음 +5.24 ≈ +1.3억 대 관측 X0N 차이 +2.67억(standard 240, c022abe 30.93 − main 28.26). 남은 약 +1.4억은 확인하지 않았다(사기·이직 없음 등 후보) `[추론]`.
   - **함의:** "수출이 빠져도 순자산이 오른다"는 상당 부분 **봇의 연봉 인상 수락 규칙이 사라진 효과**다. 수출 잠금 자체는 순자산을 깎는다(−3.4~−3.9억, 240개월).
