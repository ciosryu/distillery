4. **보통 난이도 임금은 설계대로다.** 월 급여 1,005만 → 1,252만(+24.6%, 62개월 결산 반영 후). 이 중 **정기 임금 조정(#330, 연 1% × 5회)은 61만(25%)**이고, **레벨업 인상(레벨마다 +5%, 기존 규칙 `HR_TUNING.levelRaise`)이 186만(75%)**이다. 연 급여 1.22 · 1.29 · 1.36 · 1.41 · 1.45억은 봇 평균 1.224 · 1.288 · 1.355 · 1.406 · 1.454억과 같다. 지출에서 급여 몫은 27~29%다.

## ② 3년 차 순자산 0.00억 — 실제 값이다

- 35개월째(3년 차 마지막 달) 결산의 `netWorth` = **+202,208원**(0.002억). 연 요약 `netWorthEnd`도 같은 값이고, 스크립트·화면은 억 단위 소수 둘째 자리로 반올림해 0.00으로 보인다 `[사실 — 기록]`.
- 월말 순자산: 22개월 0.64억 → 28개월 0.03억 → **29~32개월 음수(최저 30개월 −0.14억)** → 33개월부터 플러스 → 62개월 2.07억.
- 왜 음수가 되나 `[사실 — 정의 #317]`: 순자산 = 현금 + 재고·통의 처분 예상액 − 대출 잔액이다. 22개월째 대출 3억이 현금과 부채에 같이 들어가 0으로 상쇄되고, 그 뒤 매달 적자(자체 흐름 월 −1,000~−1,700만)가 현금을 깎는 동안 어린 통의 처분 예상액은 천천히 오른다.
- **같은 구간 봇 평균도 음수다:** 연말 순자산 봇 3년 차 −0.23억(최저 시드 −0.47) · 4년 차 −0.57억(−0.93) · 6차 3년 차 0.08 · 4년 차 −0.53 · 5년 차 −0.24억. **7차의 0.00 → 0.40 → 1.96억은 봇·6차보다 빨리 회복하는 경로다** — 첫 위스키가 15개월째로 일러 3~5년 차 제품 매출(2.67 · 4.26 · 4.99억)이 봇(2.34 · 3.83 · 5.71억)보다 3·4년 차는 높고 5년 차는 낮다.

## 제안 · 질문
