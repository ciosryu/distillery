  - `malt-stopped` — 몰트가 **0**일 때만 뜬다(절반 생산은 해당 없음)
- **없던 것:** 「생산 지시를 n개월 전에 줄인 뒤 그대로다 · 그 사이 재고가 바닥났다」처럼 **줄인 생산과 지금의 품절을 잇는** 신호. 7차 판에서 생산을 줄인 까닭(재고 과잉, 62개월)은 그 뒤 사라졌는데(끝에 전 제품 품절), 화면은 그 변화를 「병입하라」로만 알렸다.
- **함의:** 신호를 더할 곳은 생산 지시 쪽(PROD)이다. MGT 계산 중 쓸 만한 것: `rampOutlook`(증산 여유·판 끝까지 이익) · 「현금이 고정비 12개월치 이상」 조건 — 필요하면 PROD에 넘긴다.
