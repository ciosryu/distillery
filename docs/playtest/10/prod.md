### 2. U5 — 소주에도 붙는 증류기 스타일

**사실 `[사실 — 코드 · 세이브]`**
- `production.ts`는 형태를 고른 증류기의 원액이면 **레시피 종류와 관계없이** `SpiritLot.stillShape`를 남긴다. [결정 #429]는 **증류(맛)**만 소주를 카탈로그 값으로 돌리고, 표지는 그대로 붙였다.
- 병입하면 `blending.ts`가 LPA가 가장 많은 원액의 형태를 접어 `Product.stillStyle`을 남긴다. 그래서 소주 셋(「김포 소주」 · 「옹기소주」 · 「오크소주」)이 모두 `light`다. 탱크 소주 원액 이름에도 「· 라이트」가 붙는다.
- **뉴본 셋(그레인 · 피티드 · 언피티드)의 `light`는 맞다** — 몰트 · 그레인 원액이라 [결정 #429]대로 형태가 닿는다. PM C-6의 「뉴본」은 정정이 필요하다.

**보이는 곳**
- 피드(`feed.ts`): 스타일이 `medium`이 아니면 「라벨」 글감 가중이 오르고, 「라이트 스틸」 줄이 소주에도 뽑힐 수 있다 `[사실 — 식]`. 실제로 나왔는지는 `[확인 불가]`.
- 자동 납품 가름(`economics.ts recipeFilter`): 소주 제품 `light` · 소주 원액 `light`라 지금은 맞물린다.

**고치는 길 `[제안 — 판 뒤, PROD]`**
1. 생산: 형태를 **몰트 · 그레인 원액에만** 남긴다(한 줄 — [결정 #429]와 같은 범위).
2. **함께 꼭:** 자동 납품 스타일 가름을 위스키 원액(몰트 · 그레인)에만 건다.
   - 1만 고치면, 이미 `light`가 붙은 소주 제품이 새 소주 원액(형태 없음)과 어긋나 **자동 납품이 멈춘다.**
3. 이미 붙은 값(진행 중 세이브):
   - 피드가 위스키 계열이 아닌 제품의 `stillStyle`을 읽지 않게 막는다(MKT).
   - 또는 세이브 고침(`migrate.ts`, ARCH)으로 소주 제품 · 원액의 값을 지운다.
   - PROD 권장은 **읽는 쪽에서 막기**다. 세이브 버전을 올리지 않는다.
- 봇은 형태가 없어 출력이 그대로다.

### 3. 「옹기소주」 61 ~ 64개월 못 채움

**사실 `[사실 — 결산 · 세이브]`**
- **소주 공급:** 「증류식 소주 — 상압」 월 1배치(130 LPA)이고, **53 ~ 57개월은 생산 0**, 61 ~ 65개월은 2배치(275 LPA)였다.

  - 결산 51개월: 「자동 통입 — 소주 → 옹기 0개 · 빈 옹기가 모자라 342L 대기」(옹기가 꽉 참)

**까닭 `[추정]`**
1. **53 ~ 57개월 소주 생산 0**(생산 지시를 내렸는지는 `[확인 불가]`). 이 다섯 달 동안 옹기로 갈 소주가 없었다.

- 함의: 규칙은 설계대로 움직였고 **공급 부족**이 본 원인이다. 화면이 「소주 생산 < 소주 제품 수요」를 한 줄로 알려 주면 좋다(MKT · ARCH 탱크 소주 재고 개월 warn과 이어짐) `[제안]`.

### 4. 「숙성 점검」의 대가 — PROD 식 어림 (MGT에 전달)

**사실 `[사실 — 세이브]`**
- 디스틸러 공정 59 → 일 중 실효 41.3(× 0.7)이다. 맛볼 통(목재 84개월 이상)은 0통이다(가장 오래된 통 68개월).

**새 원액 이취 `[계산 — steadyBatch, 일 있음 대 없음]`**
| 레시피 | 품질(일 있음 → 없음) | 이취 | 초류(solvent) · 후류(feinty) |
|---|---|---|---|
| 증류식 소주 — 상압 | 51.2 → 51.3 | 3.1 → 2.9 | 후류 0.83 → 0.76 |
| 싱글 몰트 — 언피티드 | 44.4 → 44.5 | 1.3 → 1.2 | 0.42 · 0.90 → 0.38 · 0.82 |
| 싱글 몰트 — 피티드 | 43.6 → 43.7 | 1.6 → 1.5 | 0.71 · 0.89 → 0.65 · 0.82 |
| 그레인 — 옥수수 | 41.6 → 41.6 | 1.3 → 1.1 | 0.71 · 0.54 → 0.65 · 0.49 |

- **이취 배수** `offMul` = 1.25 − 0.5 × 공정 ÷ 100 → 0.955 → 1.044(**+9%**). 이 판 레시피는 초류 · 후류가 작아 **품질 −0.1** 안팎이다.
- 숙성 3 ~ 5년이면 초류 · 후류가 더 줄어(제거 d), 병입 품질 차이는 0.1 미만으로 본다 `[추정]`.
- **더운 달 발효 사고**(초산 +25 · 황 +8): 확률 × (1 − 공정 ÷ 120)이 0.51 → 0.66(상대 +29%)이다. 여름 고온 달에만 있는 드문 사건이라 판 전체로는 작다 `[추정]`.
