  - 결산에 `stockoutDemand?: { productId; bottles }[]`를 더한다(`MonthReport` — 코어 타입 한 줄, ARCH 코어 PR).
  - 판매 단계 끝에서 **최근 6개월 안에 팔린 적이 있고 지금 재고 0인(보관하지 않은) 제품**마다 `restockedDemand(s, p, moy)`를 적는다. 그달 진열과 같은 범주 나눔을 넣고, 잡음은 넣지 않는다.
  - 6개월 넘게 안 판 제품은 「그만 판 것」으로 보고 뺀다.
- **봇 출력 불변:** 난수를 쓰지 않고 상태를 바꾸지 않는다. 결산 JSON에 줄만 늘고 X0 표는 같다.
- **화면:** 연간 결산 · 분기 요약에 「품절로 못 판 병(어림) n병 · 약 m억」. 품절 배지(#965)와 같은 셈이라 화면 숫자가 서로 맞는다.
- **F5d:** 결산은 기록이라 참 품질로 센다(판매 셈과 같은 길). 화면에 「어림」으로 보이면 품질 신호가 될 수 있다. 화면은 아는 품질(`knownState`)로 다시 세거나 병 수만 보이는 쪽을 권한다 — ARCH와 맞춘다.
- **크기:** 코어 한 줄 + MKT 셈 1 PR + 화면 1 줄. 단계 T 측정 도구로 먼저 쓴다.
