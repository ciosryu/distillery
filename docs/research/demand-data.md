# 국가·지역 × 주종 기본 수요 데이터 v0.1

> 상위 문서: [PRD §9](../PRD.md) · 데이터: [`data/market/base-demand.json`](../../data/market/base-demand.json) · 생성: [`scripts/build-demand-data.mjs`](../../scripts/build-demand-data.mjs)
> 조사일: 2026-11-05 · 기준 연도: 2024 (없으면 인접 연도, 표에 명시)

## 요약

- **기본 수요는 2024년 실적이 기준이고, 단위는 9L 케이스(제품 액량)로 통일했다.** 원문 값과 단위는 JSON에 그대로 보존했다.
- **시장마다 지표 종류가 다르다.** 한국은 출고, 일본은 과세수량, 중국·대만은 수입, 미국은 공급사 판매, 독일은 공급, 스페인은 소비다. 그래서 **시장 간 절대값을 직접 비교하면 안 된다.** 대신 시장 안의 주종 비중과 추세는 비교적 믿을 만하다.
- **신뢰도가 높은 시장:** 미국(DISCUS 전 주종), 독일(BSI 원문), 한국 소주, 중국 위스키·브랜디 수입, 스카치·코냑 수출국별 통계
- **신뢰도가 낮거나 공백인 시장:** 대만(2023 대용), 캐나다(집계 사이트 값), 영국(총량만), 프랑스(대형마트 채널 한정), 필리핀·태국·베트남(총량 또는 브랜드 하한), 면세(2018년 값)
- **원문 확인 여부:** 공식 통계 포털 대부분이 이번 조사 환경에서 막혀 있었다. 그래서 상당수 값이 **검색 요약 기반**이다(`verified: snippet`). 원문으로 확인한 값은 표에 `✓`로 표시했다.

## 1. 사용법

### 1.1 레코드 역할(`role`)

| 역할 | 의미 | 게임 엔진 처리 |
|---|---|---|
| `base` | 수요 셀 | 그대로 기본 수요로 사용 |
| `total` | 상위 합계. 하위 `base`와 중복된다 | 합산 금지. 하위가 비어 있으면 **잔여 = total − Σ하위 base**로 계산 |
| `reference` | 수출, 생산, 대체값, 권역 값 | 수요로 쓰지 않고 검증·이벤트 기준값으로만 사용 |

### 1.2 카테고리 계층

```
spirits_total
├─ whisky_total ─ scotch / american_whiskey / canadian / irish / japanese_whisky / whisky_other
├─ agave_total ── tequila / mezcal
├─ brandy_total ─ cognac / armagnac / calvados
├─ vodka, gin, rum, liqueur, anise, korn_clear, fruit_brandy, white_spirits, spirits_other
└─ soju_diluted, soju_distilled, baijiu, shochu_korui, shochu_honkaku
```

게임의 생산 주종과 수요 카테고리 대응 `[제안]`:

| 생산 주종 | 수요 카테고리 |
|---|---|
| 스카치 | `scotch` |
| 버번 | `american_whiskey` |
| 한국·기타 지역 몰트 | `whisky_other` |
| 코냑 | `cognac` |
| 진 | `gin` |
| 증류식 소주 | `soju_distilled` |

### 1.3 단위 환산 규칙

| 원문 단위 | 환산 | 비고 |
|---|---|---|
| kL / 万升 / 万千升 / 亿升 | ×1,000 / ×10⁴ / ×10⁷ / ×10⁸ L | |
| 70cl 병 | ×0.7 L | SWA·BNIC·BSI 공통 |
| 톤 | ≈ ×1,000 L | **추정(±5%)**. 관세 중량 기준 |
| 순수알코올 L(영국) | ÷ 0.40 | **추정**. RTD 포함 |
| 백주 65도 환산 | 그대로 둠(`abvBasis: 0.65`) | 실제 제품 액량은 더 큼 |
| 인도 케이스 | 9L로 가정 | 확인 필요 |
| 9L 케이스 | L ÷ 9 | 출력 단위 |

## 6. 게임 설계에 주는 함의

1. **기본 수요는 3~5년 평활화해서 쓴다.** 2024년은 중국 경기 둔화, 대만 재고 조정, 미국 관세 이슈로 변동이 컸다. 단년 값을 그대로 쓰면 특정 시장이 과도하게 커지거나 작아진다.
2. **시장 간 정규화가 필요하다.** 지표 정의가 달라 절대값을 그대로 쓰면 독일(공급, 과대)이나 프랑스(대형마트 한정, 과소)처럼 왜곡된다. `[제안]` 시장 총량은 별도 기준으로 정규화하고, 시장 안의 주종 비중은 이 데이터를 쓴다. 별도 기준의 후보는 1인당 순수알코올 소비량 × 성인 인구다.
3. **신뢰도를 게임에 노출할 수 있다.** `confidence`가 낮은 셀은 "시장 조사" 행동(백오피스·영업 스탯)으로 정밀도가 올라가는 **정보 불확실성** 메커닉(PRD §5.6)과 연결할 수 있다.
4. **매크로 이벤트의 기준점으로 쓴다.** 2024년의 실제 변동을 이벤트로 옮길 수 있다.
   - 코냑 XO −26%, 중국행 −9.6%
   - 스카치 싱글몰트 수출액 −17%
   - 테킬라 생산 2022년 정점(651.5M L) 이후 감소
   - 켄터키 숙성 재고 사상 최대(1,610만 배럴)
   이 수치들이 "위스키 붐 → 공급 과잉" 이벤트(PRD §9.3, §10)의 현실적인 크기 기준이 된다.
5. **가격 기준점:** 미국 레코드의 `money`(공급사 매출) ÷ 케이스 수로 주종별 공급사 기준 케이스 단가를 얻을 수 있다. 수요 공식의 `기준가`를 보정하는 데 쓴다.
