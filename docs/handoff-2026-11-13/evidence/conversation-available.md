### 가장 중요한 구조적 문제: 캠페인 목표와 시간

**승리 판정 = 적격 원액의 실제 숙성 완료 + 적법한 병입 + 최초 유상 판매 성립**

| 조절 영역 | Easy | Normal | Hard |
|--------|--------|--------|--------|
| 거시경제 | 안정적인 경기 | 경기순환 및 완만한 충격 | 심한 경기침체·불황 |
| 시장 경쟁 | 비교적 완만한 가격 경쟁 | 일반적인 시장 경쟁 | 강한 경쟁·가격 압박 |
| 소비자 취향 | 향미 선호 거의 고정 | 완만한 유행 변화 | 급격한 유행 변화 |
| 원자재·공급망 | 공급 안정·가격 안정 | 일반적인 가격 변동 | 원자재 급등·납기 차질 |

| 금융 환경 | 비교적 유리한 대출·구제 조건 | 표준적인 신용 제약 | 높은 차입 부담·엄격한 심사 |

각 영역은 독립적으로 선택하지만, 동일한 원인에서 발생하는 경제 충격을 중복 계산하지 않도록 설계합니다. 예를 들어 거시경제 침체에 따른 소비 위축과 시장 경쟁 강도는 별개의 효과를 갖도록 구분합니다.

초기 자본금, 시작 지역, 설비 구성은 기존 창업 준비 화면에서 결정하고 Custom 난이도에서 다시 조정하지 않습니다.

Easy / Normal / Hard는 사전에 정의된 6개 설정값의 묶음이며, Custom은 그 설정값을 개별적으로 변경하는 방식입니다. 따라서 네 가지 모드가 서로 다른 시뮬레이션 엔진을 사용하지 않습니다.

**변경하지 않을 기본 원칙\:** 숙성의 물리적 인과관계, 숨겨진 실제 품질, 샘플링의 정보 오차, 자체 증류한 15년 숙성 싱글 몰트 위스키의 캠페인 승리 조건은 난이도로 제거하지 않습니다.

## 4\. 엣지 케이스와 정책

| 문제 | 확정할 처리 방식 |
|--------|--------|
| 프리셋에서 설정 하나만 변경 | 자동으로 Custom 전환 |
| Custom에서 6개 설정을 모두 Normal로 변경 | Custom 표시 유지, Normal과 동일한 실행 파라미터 사용 |
| 플레이 중 난이도 변경 | 불가. 새 게임 시작 시에만 변경 가능 |
| Custom의 공식 리더보드 | 일반 프리셋 순위와 분리 |
| 동일 설정·시드 재실행 | 동일한 난수 결과 보장 |
| Hard 요소 여러 개의 중첩 | 복합 위험을 감지하고 시작 전 경고 |

단, Custom의 모든 조합을 각각 동일한 수준으로 밸런싱하는 것은 현실적으로 어렵습니다. 공식 프리셋은 10\~40개 이상의 시드로 생존율과 지배 전략을 검증하고, Custom은 설정 간 극단적인 상호작용을 별도로 검증해야 합니다.

## 5\. 개발 우선순위

**MVP에 Custom을 포함**하겠습니다. 기존 난이도 시스템의 설정값을 독립적으로 분리하는 작업이기 때문에 정식판까지 미룰 이유가 적습니다.

정식판에서는 설정 프리셋 저장·불러오기, 커뮤니티 공유용 설정 코드, 고급 설정 확장을 추가할 수 있습니다.

**최종 확정\:** Easy / Normal / Hard는 간편 프리셋으로 유지하고, Custom에서는 6가지 핵심 경영 위험을 독립적으로 선택합니다. 초기 구현에서는 3단계 선택 방식을 채택하고, 검증되지 않은 세부 수치 슬라이더는 도입하지 않습니다.

이 결정은 별도 추가 질문 없이 설계에 반영하겠습니다.
