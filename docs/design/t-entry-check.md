## 4. 반론·리스크
- 3·6단계는 "끝까지 돈다"만 자동으로 본다. 수치 판단(보호 효과·기준선 변화)은 사람이 본다. 자동 합격선을 두면 단계 T 튜닝 전에 수치를 확정하는 셈이라 두지 않았다.
- 화면 점검은 봇 세이브라 사람 판의 경로(태그를 직접 붙임·정책 바꾸기)를 덮지 않는다. 사람 후반 판 세이브가 있으면 `HUMAN_SAVE`로 함께 돌린다.
