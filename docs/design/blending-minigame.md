## 0. 요약

- **오너 원안 (결정 #99):** 마스터 블렌더의 능력을 시험하는 "전술판". 원액마다 6가지 향미 스탯(피트·과일·플로럴·스파이시·우디·스위트) 육각형이 있고, 시장 트렌드나 평론가가 요구하는 **목표 육각형**에 맞춰 여러 캐스크를 **% 비율로 배팅(vatting)** 한다. 블렌더 레벨이 높을수록 **배팅 전 예상 차트와 실제 결과의 오차**가 줄어든다
- **설계 판단 3가지**
  1. 육각형은 36축 향미 모델의 **투영(view)** 이다. 새 스탯을 따로 저장하지 않는다 → 향미 수치의 출처가 하나로 유지되고, 숙성·캐스크·기후가 바꾼 향미가 그대로 육각형에 반영된다
  2. 투영이 **선형**이라, 만들 수 있는 맛은 **가진 캐스크 육각형들의 볼록 껍질 안**뿐이다. "재고가 곧 전술 폭" — FM의 스쿼드 뎁스와 같은 긴장이 생긴다
  3. 결과는 결정론, 불확실한 건 **블렌더가 읽은 값(정보)** 이다 — PRD #18 "확률은 결과가 아니라 정보에"와 정확히 맞는다
- **재미를 위한 핵심 제안:** 선형 평균만 있으면 "계산기 퍼즐"이 된다. 판단이 남도록 ① 불확실성을 **띠로 보여 주고 정보를 사게** 하고 ② **재고 소모·연수 표기·병 수 같은 제약**을 걸고 ③ 목표를 **트렌드·평론가 의뢰·코어 레인지 재현** 3종으로 나누고 ④ 결과 **공개 연출**과 **위임**을 넣는다 (§4)

## 1. 원안 → 시스템 대응

| 원안 요소 | 시스템 | 구현 |
|---|---|---|
| 육각형 6스탯 | 36축 향미 → 6스탯 선형 투영 (§2) | `hexOf`, `HEX_PROJECTION` |
| 숙성 연수·캐스크에 따라 달라짐 | 숙성 모델(추출·제거·반응)이 36축을 바꾸므로 자동 반영 | 기존 `matureCask` |
| % 비율 배팅 | 알코올(LPA) 기준 비율 — 투영이 선형이라 슬라이더와 차트가 정확히 비례 | `mixHex`, `previewVat` |
| 목표 레이더 | `BlendTarget` (출처·목표 육각형·허용 폭·축별 중요도·마감) | `matchScore` |
| 블렌더 레벨 → 오차 감소 | 캐스크별 지각 오차 σ = f(레벨, 후각), 샘플링으로 추가 감소 | `perceptionSigma`, `perceivedHex` |

**왜 알코올 기준 %인가:** 기존 블렌딩(§6.1)은 향미를 LPA 가중 평균한다. 화면 %를 부피로 두면 도수가 다른 원액을 섞을 때 슬라이더와 차트가 어긋나 보인다. 화면 %를 LPA 기준으로 두면 "슬라이더 10% = 차트 10% 이동"이 그대로 성립한다. 병 수·부피는 옆에 따로 보여 준다.

## 3. 블렌더의 지각 — "예상 차트"는 어떻게 틀리나

```
캐스크 i의 읽은 값  = 실제 육각형 + N(0, σ_i)          (축마다, 시드·캐스크·블렌더·샘플 수로 고정)
σ_i               = 14 × (1 − 후각/150) / (1 + 0.15 × (레벨 − 1)) / √(1 + 샘플 수)     (최소 1.5)
예상 블렌드         = Σ 비율_i × 읽은 값_i
예상 오차 띠(1σ)    = √ Σ (비율_i × σ_i)²
실제 블렌드         = Σ 비율_i × 실제 육각형_i            (결정론)
```

| 블렌더 | 캐스크 1개 σ | 4개를 같은 비율로 섞을 때 띠 |
|---|---|---|
| 없음(대표가 직접) | 19.6 | 9.8 |
| 레벨 1 · 후각 40 | 10.3 | 5.1 |
| 레벨 8 · 후각 85 | 3.0 | 1.5 |

- **오차는 고정값이다.** 같은 캐스크를 다시 열어도 같은 예상 차트가 나온다 → 창을 닫았다 열어 다시 굴리는 스커밍이 통하지 않는다. 바꾸려면 **샘플을 더 떠야** 한다(비용·원액 손실)
- **여러 캐스크를 섞으면 오차가 서로 상쇄돼 띠가 좁아진다** (실제 블렌더의 경험칙과 같다). 반대로 싱글 캐스크는 예측이 가장 어렵다 → "싱글 캐스크 = 도박, 블렌드 = 안정"이라는 자연스러운 긴장
- **블렌더 직군:** PRD §7.1에는 마스터 블렌더(후각·미각·직관·감정력)가 있지만 코드에는 아직 없다 → §6 질문 1

## 4. 더 재미있게 만드는 법 `[제안 — 승인 요청]`

먼저 위험부터. **원안 그대로(선형 평균 + 거리 점수)면 수학적으로는 선형계획 문제다.** 정보가 완전하면 최적 비율이 한 번에 계산되고, 그 순간 미니게임은 계산기가 된다. 재미는 "정답이 계산되지 않는 곳" — 정보의 불완전함, 되돌릴 수 없는 자원 소모, 목표의 다양성 — 에서 나온다. 아래 제안은 그 세 곳을 채운다.

### P1. 불확실성을 "띠"로 그리고, 정보를 사게 한다 ★ 핵심

- 예상 차트를 선이 아니라 **±1σ 띠**로 그린다. 목표 육각형이 띠 안에 들어오면 "아마 맞을 것"
- 정보를 사는 세 가지 수단 (PRD §5.6과 같은 구조):

| 수단 | 비용 | 효과 |
|---|---|---|
| 노징 (기본) | 무료 | 블렌더 기본 σ |
| 샘플 테이스팅 | 캐스크당 0.5L 손실 + 소액 | σ ÷ √(1+n) |
| 실험실 분석(GC) | 설비 + 건당 비용 | 피트·우디 두 축만 σ ≈ 1 |

- **판단:** 샘플을 계속 뜨면 정확해지지만 원액이 줄고 시간이 든다. "충분히 안다"고 멈추는 순간이 플레이어의 결정이다

### P2. 볼록 껍질을 보여 주고, 재고를 태우게 한다 ★ 핵심

- 화면에 "지금 재고로 만들 수 있는 영역"을 옅게 그린다. 목표가 영역 밖이면 **어떤 비율로도 못 맞춘다** → 원액 브로커 매입, 피니싱, 다른 캐스크 숙성으로 영역을 넓혀야 한다
- 배팅에 쓴 캐스크는 사라진다. **대만 올로로소 8년 같은 극단 캐스크는 영역의 꼭짓점**이라, 써 버리면 다음 블렌드에서 그 방향을 못 낸다 → "지금 이 의뢰에 꼭짓점을 쓸까, 아껴 둘까"가 FM의 "주전을 이번 경기에 쓸까"와 같은 긴장
- 비용이 없다. 이미 있는 시스템(재고·매입·피니싱)이 전술 폭을 정한다

### P3. 제약이 퍼즐을 만든다

목표 육각형 하나만 맞추는 게 아니라 동시에 지켜야 할 것:

| 제약 | 이미 있는 규칙 | 긴장 |
|---|---|---|
| 숙성 연수 표기 = 가장 어린 원액 (§6.2) | 있음 | 어린 버번 배럴로 우디를 희석하면 라벨 연수가 떨어진다 |
| 병 수 목표 | 병입 옵션 | 소량 고가 캐스크만으로는 병 수가 안 나온다 |
| 원가·가격 | 원가 추적 | 오래된 원액일수록 비싸다 |
| 도수 | 최소 병입 도수 | 증발로 도수가 떨어진 캐스크 |

### P4. 비선형은 딱 두 개, 화면에 규칙을 공개한다

- **마스킹:** 피트가 강하면 플로럴·과일이 덜 느껴진다(예: 피트 30 초과분 × 0.3만큼 플로럴 감소). PRD §6.1에 이미 있는 개념
- **매링:** 섞은 뒤 n개월 두면 '통합감'이 오르고 육각형이 약간 둥글어진다(극단값이 평균 쪽으로). 시간을 쓰면 점수가 오른다
- **반론:** 비선형을 늘릴수록 플레이어는 "왜 이렇게 됐지?"를 이해 못 한다. 그래서 두 개로 제한하고, 블렌딩 화면에 규칙 카드를 띄운다

### P5. 목표 3종 — 반복해도 지루하지 않게 ★ 핵심

| 목표 | 출처 | 허용 폭 | 보상 | 주기 |
|---|---|---|---|---|
| **트렌드** | 시장 국면 (지금의 피트·셰리 유행을 육각형으로 일반화) | 넓음 (15) | 그 제품의 매력도 배수 | 수년 주기로 이동 |
| **평론가 의뢰** | 이벤트 — 실명 평론가·품평회(§11.1) | 좁음 (5~8), 축별 중요도 ("피트만큼은 정확히") | 일회성: 인지도·한정판 가격 프리미엄 | 마감 있음 (예: 6개월) |
| **코어 레인지 재현** | 내 제품의 지난 배치 육각형 | 중간 (8) | 일관성 → 그 라인의 재구매(매력도) | 매 병입 |

- **코어 레인지 재현이 장기 재미의 핵심이다.** 실제 마스터 블렌더의 주 업무는 "작년과 같은 맛을, 작년과 다른 캐스크로" 만드는 일이다. 재고가 매년 바뀌니 같은 정답이 두 번 나오지 않는다
- 트렌드는 지금의 이진 보정치(`appeal:peated`·`appeal:sherried`)를 육각형 목표로 일반화하는 것 → 기존 시장 국면 이벤트를 그대로 살리면서 더 세밀해진다

### P6. 결과 공개 연출 — 도파민은 "공개" 순간에

- 배팅 확정 → (매링 기간) → **실제 차트가 예상 띠 위에 겹쳐 그려지며 공개**. 띠 안에 들어왔는지가 한눈에 보인다(FM의 경기 결과 화면)
- 차이가 큰 축으로 **평론 문구를 자동 생성**한다: "우디함이 기대보다 강하다", "피트가 과일을 덮었다"(마스킹 발동 시) — 왜 틀렸는지 배우게 한다
- 실명 평론가 문장은 만들지 않는다(PRD §11.1 — 인물 발언 금지). 문구는 하우스 테이스팅 노트 형식

### P7. 위임 — 30년 360턴의 반복 피로를 막는다

- "블렌더에게 맡기기": 목표만 주면 블렌더가 비율을 정한다. 결과는 **블렌더가 읽은 값 기준의 최적** → 블렌더가 서툴면 실제 점수가 떨어진다. 블렌더를 키울 이유가 된다
- 기존 "빠른 병입"(지금의 블렌딩·병입 화면)은 그대로 둔다. 미니게임은 **목표가 있을 때만** 보상이 있다 → 강제 미니게임이 아니다

### P8. 레어 캐스크 발견 (확장)

- 샘플을 뜨다가 육각형이 극단적으로 튀는 캐스크를 발견 → **싱글 캐스크 출시** 선택지(PRD §6.3 제품 형태). 이미 있는 "레어 캐스크" 개념(§5.6)과 연결

### 함정과 대응

| 함정 | 대응 |
|---|---|
| 육각형은 완벽한데 평이 나쁘다 → 배신감 | 육각형 옆에 **결함 게이지**(이취: 유황·퓨젤·곰팡이)와 **통합감 바**를 같이 보여 준다. 육각형은 36축의 일부만 보여 주기 때문이다 |
| 캐스크 2,500개 중에서 고르기 | 같은 배치·같은 통입 달의 캐스크를 **묶음(코호트)** 으로 보여 주고, 묶음 단위로 비율을 준다 (architecture §3.4 batchId) |
| 고레벨 "추천 조합"(PRD §6.1)이 미니게임을 없앤다 | 추천도 **블렌더가 읽은 값 기준** — 레벨이 높으면 좋은 추천, 낮으면 엉뚱한 추천 |
| 모든 병입이 미니게임이 된다 | 빠른 병입 유지, 보상은 목표가 있을 때만 (P7) |

**설계 메모 — 의뢰는 왜 이벤트가 아닌가:** 이벤트 엔진은 매달 목록 전체를 섞어 판정한다. 의뢰를 이벤트로 넣으면 모든 시드의 이벤트 순서가 바뀌어(시드 1에서 1월 한파가 새로 생김) 밸런스 비교가 깨진다 → 원액 계약 제안처럼 독립 스트림('commissions')으로 굴린다 ([architecture.md §9.3](architecture.md))
