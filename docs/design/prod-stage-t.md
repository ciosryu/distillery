## 항목별

### T-PROD-1 플래그십 예비 통 수 (#259 · #260)
- **근거:** 후반 확인 판(§7.18 1) — 2·3년 표기 제품의 자동 납품이 "어린 통부터" 쓰다가 소비(연 23~33통)가 자동 통입(연 10~20통)을 넘었다. 그러자 플래그십 후보 50통을 모두 썼다. 오너: "몰랐다, 장기 숙성용 캐스크가 모두 소진되어 곤란"
- **지금 규칙 둘이 다르다:** 게임은 자동 납품에서 **4통**을 지킨다(#259, `PROD_TUNING.flagshipReserve`). 태그 설계(#260)는 기본 **2통**이다. P7 봇 재현에서는 2통만 지켜도 10/10 판에서 플래그십이 가능했다(W3, 비용 순자산 −0.50억 ≈ 5%). 5통은 2통과 차이가 없었다(W4 대 W5). → 태그가 들어오면 둘 중 하나로 맞춘다. 단계 T 측정 전까지는 4통 그대로 둔다(태그로 옮길 때 숫자를 바꾸면 출력이 바뀐다)
- **손잡이:** `PROD_TUNING.flagshipReserve`(환경 변수 `FLAGSHIP_RESERVE`), 보호 대상(지금: 후보 중 가장 오래된 n통, 고객 소유·오염 확인 통 제외)
- **측정:** P8 X0 대 X3(예비 4통)은 이미 있다(10시드: standard 21.50억 대 21.13억, micro 같음). **다만 P8은 게임의 자동 납품을 쓰지 않고 자기 병입 규칙으로 보호를 흉내 낸다**(`protect` — 가장 오래된 n통은 병입하지 않음). 그래서 게임 규칙(자동 납품 + 예비)을 그대로 재지 못한다 → **MGT에 요청 `[제안]`:** P8에 "위스키 계열은 게임의 자동 납품(#206)을 켜고 보충한다" 선택(`AUTORESTOCK=1`)을 단다. 그러면 `FLAGSHIP_RESERVE=0,2,4,6`을 그대로 돌릴 수 있다
- **볼 것:** 플래그십 가능 판 수(후보 36·72·108·144개월), 자동 납품 "원액 없음" 달 수(#243 알림), 15년 순자산, 플래그십 품질
- **반론:** 예비가 크면 2·3년 표기 제품이 일찍 "원액 없음"이 된다. 그것은 "생산을 늘려라"는 신호라 의도에 맞다(#252 반론) — 다만 신호를 못 읽는 사람에게는 매출 공백으로만 보인다(P-PROD-30과 같은 문제)

### T-PROD-2 표준 규모 8년 차 뒤 공급 (ARCH §7.21 5)
- **근거:** 후반 판 166개월째 순자산 21.14억(목표 24억), 13년 차 → 14년 차에 줄었다. 위스키 판매 8,724병(7년 차) → 762병(14년 차, 10개월). 141~159개월에는 1년 표기 제품도 8번 못 채웠다. 숙성고 150자리 중 최대 75통(50%)만 썼고, 연 생산 LPA는 소규모 4차와 같은 띠(5,200~7,100)였다 — **규모가 커져도 생산을 늘리지 않았다**
- **나눠 볼 원인:** ① 생산 지시(사람이 안 늘렸다 — 행동) ② 설비 상한(1,000L 증류기 1기, MVP에서 증류기 추가가 잠김 — 구조) ③ 통입 속도(자동 통입 6개월마다 — 설정) ④ 수출 수요(8년 차 뒤 수요가 크게 는다 — MKT)
- **측정:** P8 X0에서 몰트 배치 4(지금)·5·6 × 이벤트 켬, 연차별 위스키 판매·숙성 통 수·숙성고 사용률. 6배치가 설비로 안 되면 ②가 원인이다
- **판정:** ①·③이면 화면 안내(단계 P로 돌려 작은 PR)나 봇 정책 문제다. ②면 **구조**다(MVP 증류기 잠금 풀기) — 단계 T에서 바꾸지 못한다. 단계 P로 되돌려 오너 결정을 받는다(PROCESS §2)
- **주의:** MGT M3 예비 측정(standard에서 몰트 위주가 순자산 1위, mgt-stage-t.md)과 같은 질문의 다른 면이다. "몰트를 늘리는 것이 늘 정답인가"(몰트 배치의 한계 수익)는 단계 T 밸런스로 BAL이 본다 — PROD는 **"늘릴 수 있는가"**(설비·숙성고)를 본다

### T-PROD-3 생산 건너뛰기 기준 (#267 · #268)
- **근거:** qol.md §3 P6 실험(10시드, 이벤트 끔, **소주까지 멈춘** 실험) — n = 0.5에서 건강한 판 19.80억 그대로, 무너지는 판 파산 102 → 130개월. n ≥ 2는 함정(n = 3이면 4차 판 목표 7/10)
- **다시 잴 것:** 실제 규칙은 **위스키 원액만** 멈추고 소주는 계속 만든다. 그리고 P8은 이벤트를 켠다. 같은 결론인지 본다
- **손잡이:** `PROD_TUNING.whiskySkipFixedMonths`(환경 변수 `WHISKY_SKIP`, 끄려면 `-1e12`)
- **측정:** P8 X0·X2(약한 판)와 `mvp-survival` 4전략에서 `WHISKY_SKIP=-1e12,0.5,1`. 건너뛴 달 수(`MonthReport.whiskySkipped`), 파산 수·시점, 15년 순자산

### T-PROD-4 자동 납품 목표 속도 (#255)
- **근거:** 후반 판 「셰리 블렌드」 재고 1,798병 = 58개월치(§7.18 2). 자동 납품(2개월분)이 판매 꼭대기에서 채웠고, 그 뒤 판매가 꺾였다 `[추정 — 월별 재고 기록 없음]`
- **결정된 방향(#255):** 판매 속도를 max가 아니라 최근 3개월 평균과 수요의 작은 쪽(또는 중앙값)으로. **수치 성격이 있어 단계 T와 같이 본다** — 구현은 P-PROD-40(단계 T 뒤 목록). 순서는 오너가 정한다: T에서 측정만 하고 구현은 뒤로 / 구현을 T 앞에 단계 P 작은 PR로
- **측정 도구:** 아직 없다. MKT `mkt-replay.ts`(세이브 재생)에 자동 납품을 켠 변형을 더하는 쪽이 가장 싸다(MKT T-MKT-3 매몰 원가와 같은 판) — **MKT와 같이**
- **연결:** MKT T-MKT-3(자동 가격이 재고 과잉을 보지 않음)은 이것이 먼저다(PM 의견)

### T-PROD-5 병입비 (#163 · P-PROD-22, 보류)
- **근거:** 오너 보류(2026-11-09) — 단계 P 수치 변경이고, 샌드박스 스모크 파산 합계가 11 → 5로 바뀌는 기준선 변화다. 사람 판에서 병입비는 매출의 10~24%(4차)·11~20%(5차)로 판을 가르지 않았다(§7.15·§7.17)
- **측정:** 병입비 인하는 `content/market.ts`(MKT 소유)·`content/catalog.ts`의 값이다. 단계 T에서 BAL이 −20%를 P8·샌드박스 8입지 40시드로 잰다(손잡이가 필요하면 MKT·PROD가 그때 단다)
- **판정 `[제안]`:** 목표 달성 수가 10%p 이상 바뀌지 않으면 #163은 닫는다. 버튼 강조(화면만)는 이미 떼어 낼 수 있게 적어 두었다(§7.15)

### T-PROD-6 어린 위스키 인식 곡선
- **근거:** MVP 첫 위스키는 13~17개월째에 나온다. 1년 위스키는 권장가·매력도가 ×0.77이다. 초반 현금이 이 값에 달려 있다 — MKT T-MKT-11
- **이번에 한 것:** 곡선이 `blending.ts`에 박혀 있어 MKT 실험에서 바꿀 수 없었다(mkt-stage-t.md T-MKT-11 측정 절). → `PROD_TUNING.youngWhiskyFloor`(0.4)·`youngWhiskyCurve`(0.8), 환경 변수 `YOUNG_FLOOR`·`YOUNG_CURVE`로 뺐다(아래 T-0, 기본값에서 출력 불변)
- **판정은 MKT 기준을 따른다.** PROD는 "곡선을 바꾸면 숙성을 기다리는 이유(3년 표기 1.18)가 약해지지 않는가"만 같이 본다 — 기준 `[제안]`: 24개월 인식이 1.0을 넘지 않는다(지금 0.98)

### T-PROD-7 플래그십 S 품질 80
- **근거:** §7.15 3 — 4차 플래그십 「10년」 품질 75.1. S등급 기준은 80(`progress.ts` `GRADE.sFlagshipQuality`, META 소유). 같은 판의 5~6년 제품은 80~82였다. 180개월 안에 12년이 되려면 **36개월 안에 통입한 통**만 쓸 수 있다 → 판 후반의 실력 향상(레시피·직원 레벨)은 플래그십에 못 들어간다. 봇도 S가 0이다(§3 20시드)
- **먼저 물을 것(오너):** "S = 1~3년 차에 좋은 통을 골라 12년 남기는 게임"이 의도인가. 의도라면 기준 80을 두고 "가능한 판이 있는가"만 본다. 의도가 아니면 대안: 기준을 기후별로(한국 75) / 플래그십 숙성을 10년으로(구조 — 단계 P)
- **PROD 측정:** P8 X0에서 플래그십 품질 분포(시드별), 그리고 "3년 차까지 통입한 통 중 품질 상위 2통을 예비로" 바꾼 변형(보호 대상을 오래된 순 → 품질 순). 품질 순 보호는 규칙 변경이라 실험 안에서만 한다

### T-PROD-8 샘플 추정 오차
- **근거:** MVP는 블렌더가 없어 대표가 맛본다. 첫 샘플 ±14(실측 참 65 → 추정 86), 샘플마다 1/√(1+n)(#143 `QUALITY_SIGMA_PER_HEX`). 4·5차·후반 판에서 오너가 이 오차로 곤란했다는 말은 없다 `[확인 불가 — 묻지 않았다]`
- **측정:** 봇이 아니라 사람 판 관찰이다. 단계 T 첫 사람 판(또는 외부 테스트)에서 묻는다. 수치를 바꾸면 봇 출력은 바뀌지 않는다(봇은 참값으로 고른다)
