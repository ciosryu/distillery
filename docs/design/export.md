# 수출 시장 레이어 설계 v0.3

> 상위 문서: [PRD](../PRD.md) §17 · 관련: [지역 특성](regions.md) §4.4(영국)·§5 Tier 2 · 상태: **구현됨 — 기준 브랜치 수출 시스템(#95, 미국·영국·공항 면세점)을 확장(#100~#107)**. 밸런스 검증 결과는 PRD §17. 수치는 모두 `[제안]`·`[튜닝]`, 사실관계는 2026-11-06 웹 확인·오너 확인 기준이며 확인 못 한 값은 `[확인 필요]`로 표시한다.

## 0. 요약

- **왜:** 스코틀랜드는 생산의 대부분을 수출한다(스카치 수출 2024년 £5.4bn). 국내 시장만 있는 지금 엔진으로는 스코틀랜드 경제가 성립하지 않는다. 또 지금의 한국·일본·대만은 판로가 국내 하나뿐이라 "숙성 재고를 어디에 팔지"라는 선택이 없다 — 브랜드형 지배(PRD §16.24)의 한 원인으로 본다 `[추측]`
- **무엇:** 수출 시장 7곳. 시장마다 관세(원산지별)·수입국 주세·물류비·시장 규모·**현지 인지도(0에서 시작)**가 다르다. 시장에 들어가려면 **수입사와 계약**한다
- **MVP 범위:** 수입사 계약·관세·수입국 주세·물류·현지 인지도. 환율·라벨 규정·앰배서더·반덤핑은 후속
- **기대 효과:** "국내 브랜드냐, 수출 브랜드냐, 원액 B2B냐"가 갈리는 판 구조. 숙성 위스키의 판로가 넓어져 확장형·혼합형에도 출구가 생긴다
- **가장 큰 위험:** 기존 3국 8개 입지의 밸런스가 전부 다시 흔들린다

## 1. 설계 원칙

| # | 원칙 | 내용 |
|---|---|---|
| 1 | **수출은 공짜 수요가 아니다** | 국내보다 마진이 얇다(수입사 매입가는 출고가보다 낮다). 대신 시장이 크고, 현지 인지도를 키우면 커진다 |
| 2 | **현지 인지도는 시장마다 따로** | 국내 인지도와 별개로 0에서 시작. 수입사 마케팅 분담·판매 입소문·수상으로 오른다 |
| 3 | **관세는 원산지와 목적지의 쌍** | 같은 미국 시장이라도 일본산 15%, 영국산 10%처럼 다르다. 표(§2.2) 하나로 관리 |
| 4 | **실제 제도를 메커닉으로** | 미국 소규모 증류소 연방 주세 감면(CBMA), 중국 잠정 세율, 싱가포르 순알코올 종량세처럼 실제 규정이 재미를 만든다 |
| 5 | **정책 변동은 이벤트로** | 2025~2026년 미국 관세처럼 자주 바뀌는 값은 고정값이 아니라 기본값 + 관세 이벤트(인상·인하)로 다룬다 |

## 3. 수입사 계약

### 3.1 흐름

1. **제안:** 시장마다 가끔 수입사 제안이 들어온다(기존 B2B 계약 제안과 같은 방식). 현지 인지도·수상·품질이 높을수록 제안이 잦고 조건이 좋다
2. **조건:** 매입가(출고가 × 비율), 최소 연간 물량, 기간, 마케팅 분담, 결제 지연, 독점 여부
3. **판매:** 수입사가 현지 수요만큼 사 간다(재주문). 현지 수요 = 현지 시장 × 현지 인지도 × 수입사 커버리지 × 매력도 × 가격 탄력성 — 기존 `demandFor`와 같은 식
4. **갱신·해지:** 최소 물량 미달이 이어지거나 현지 재고가 쌓이면 수입사가 갱신을 거절한다. 우리가 해지하면 위약금

### 3.2 계약 조건 `[제안·튜닝]`

| 항목 | 기본값 | 근거·의도 |
|---|---|---|
| 매입가 | ~~출고가 × 0.55~0.7~~ → **출고가 × 0.85~1.0** (v0.3, #106) | 수입사 마진은 현지 유통 배수(미국 ×3.0 = 수입상 ~24%·도매·소매)에 이미 들어 있다. 신생 브랜드 할인만 남긴다 (증류주 전용 통계는 못 찾음 `[추측]`) |
| 최소 연간 물량 | 1,200~6,000병 | 작은 증류소도 들어갈 수 있게 |
| 기간 | 24~36개월 | 현지 인지도가 쌓일 시간 |
| 마케팅 분담 | 월 100만~500만 원 (우리 부담) | 현지 인지도 투자. 내면 인지도가 빨리 오른다 |
| 결제 | 3개월 뒤 | 수출 대금은 늦게 들어온다 → 현금 흐름 부담 |
| 독점 | 시장당 수입사 1곳 | MVP 단순화 |
| 진입비 | 시장 개척비 0.3~1억 (라벨·등록) `[제안]` | 아무 시장이나 다 들어가는 것을 막는다 |

### 3.3 현지 인지도

- 시장마다 `exportAwareness[market]` 0~1, 시작값 0
- 오르는 길: 수입사 마케팅 분담(주), 현지 판매 입소문, 국제 품평회 수상(기존 이벤트 확장)
- 떨어지는 길: 망각(월 감쇠), 수입사 해지 시 크게 하락
- 국내 인지도의 일부가 넘어가는 **후광**(예: ×0.1)은 넣지 않는다 `[제안]` — 내수 1등이 자동으로 수출 1등이 되면 선택이 사라진다

## 4. 데이터 구조 (초안)

```ts
type ExportMarketId = 'KR' | 'JP' | 'TW' | 'US' | 'EU' | 'CN' | 'SEA';

interface ExportMarketDef {
  id: ExportMarketId; nameKo: string;
  market: Record<ProductCategory, MarketDef>;      // 기존 3국은 REGIONS 재사용 + 외국 브랜드 점유 상한 배수
  tax: { adValorem: number; specificPerLPA: number; vat: number; smallProducerPerLPA?: { upToLPA: number; rate: number } };
  retailMarkup: number; seasonality: number[];
  logisticsPerBottle: Record<RegionId | 'UK', number>; // 원산지별 국제 물류
}
const TARIFF: Record<OriginId, Partial<Record<ExportMarketId, number>>>; // §2.2 표

interface DistributorOffer { id; market: ExportMarketId; partner: string; priceFactor; minBottlesPerYear; termMonths; marketingPerMonth; paymentDelay; entryCost; expiresMonth }
interface DistributorContract extends DistributorOffer { startMonth; bottlesThisYear; stock: number /* 수입사 현지 재고 */ }
// GameState: exportAwareness: Partial<Record<ExportMarketId, number>>; distributorOffers; distributorContracts
```

- 기존 `receivables`(경기 대형 유통 납품 대금)를 수출 대금에도 그대로 쓴다
- 자기 나라는 수출 대상에서 빠진다(한국 증류소의 한국 시장 = 국내)

## 5. 범위

| 단계 | 내용 |
|---|---|
| **MVP (이번)** | 시장 7곳, 관세 표, 수입국 주세, 수입사 계약(제안·체결·재주문·갱신·해지), 현지 인지도, 수출 탭 화면, 관세 이벤트 2~3개, balance-sim 수출 전략 |
| 후속 | 환율 변동, 라벨·등록 규정(미국 COLA 등), 앰배서더(regions.md 원안), 반덤핑·보복 관세 시나리오, 베트남·태국 분리, 면세(글로벌 트래블 리테일) |
| 그다음 | 스코틀랜드(스페이사이드 → 아일라) 국가 추가 — 영국 세제·스카치 규정·수출 의존 |

## 6. 밸런스 가설과 검증 계획

- **가설 1:** 수출이 숙성 위스키의 두 번째 판로가 되어, 브랜드형 지배(이란 70%)가 줄어든다 `[추측]` → **기각 (v0.3)**: 봇 원액은 정해진 양이고 국내 수요가 더 커서 수출은 국내 판매를 대신할 뿐이었다. 지배가 줄어든 첫 결과는 브랜드형이 가장 많이 잃은 탓(PRD §17.2)
- **가설 2:** 미국 CBMA 감면 때문에 작은 증류소일수록 미국 수출이 유리하다 → 확장형과 충돌하는 선택이 생긴다
- **검증:** balance-sim에 `export` 전략(브랜드형 + 수입사 계약 2곳) 추가 → 기존 8개 입지 20시드. 목표: 지배 전략 기준(최다 1위 60% 이하) 유지, 수출 전략이 어느 입지에선 1위
- **실패 신호:** 수출 전략이 모든 입지를 지배(수출이 공짜 수요가 된 경우) 또는 아무 데서도 1위가 없음(죽은 선택지)

## 7. 반론과 리스크

1. **범위가 크다.** 데이터(시장 4곳 신규)·세제·계약·화면·봇까지 한 번에 바뀐다. MVP라도 지금까지의 입지 특성 이식과 비슷한 규모다
2. **기존 밸런스 재조정이 불가피하다.** 8개 입지 결과가 다시 바뀐다. 기준 브랜치 쪽 작업(다른 세션)과 충돌할 가능성이 크다 → 결정 번호 #95~, PRD §17로 미리 분리
3. **관세 사실관계가 불안정하다.** 2025~2026년 미국 관세는 자료마다 시점·중첩 여부가 다르다. 고정값보다 이벤트로 다루는 이유
4. **수출 수요 공식이 √n 문제(PRD §15.3 #12)를 물려받는다.** 시장이 늘면 "제품을 여러 시장에 내는" 것만으로 총수요가 커질 수 있다 → 시장별 제품 수로 나누는지 결정 필요
