## 0. 요약

> **v0.2 현황:** 구조(#58)·하드 락(#59)·Tier 1 구현(#60)이 결정됐다. 아래 표의 변경 3번 중 "절대값 제거"는 **원안 하드 락 3건만 예외로 유지**한다(오너 결정).

**결론:** 원안의 방향(지역마다 뚜렷한 보너스와 대가)은 유지한다. 다만 그대로 넣으면 ① 엔진이 표현할 수 없는 문장형 효과, ② 판을 한 번에 끝내는 절대값, ③ 사실과 다른 설정이 섞여 있어 아래 다섯 가지를 바꿨다.

| # | 변경 | 이유 |
|---|---|---|
| 1 | **국가(Country) / 산지(Site) 2단 구조** | 아일라·스페이사이드는 세금·내수 시장이 같고 기후·원료만 다르다. 지금의 `RegionDef`는 둘을 한데 묶고 있다 → 세제·시장·법규는 국가에, 기후·물·원료·고유 특성은 산지에 둔다 |
| 2 | **확률형 결과 → 결정론 + 정보 불확실성** | "오버오크 확률 30%", "빈 통이 될 확률", "발효액 통째로 폐기"는 결정 #18(확률은 결과가 아니라 정보에)과 충돌한다. 엔진의 숙성 모델로 돌려 보니 **켄터키 오버오크·이란 증발은 주사위 없이도 자연 발생**한다(§2.3) |
| 3 | **절대값 제거** | "원재료비 0", "무한대의 현금", "즉시 게임오버", "올스톱", "B2C 전면 금지"는 지배 전략이나 즉사 함정을 만든다 → 상한이 있는 배수, 단계형 제재, 대응 수단이 있는 리스크로 바꿨다 |
| 4 | **사실관계 교정** | 예: 런던 드라이 진은 GI가 아니라 제조 방식 정의, 3회 증류는 수율을 올리지 않는다, 바베이도스는 당밀을 수입한다, 버번은 미국 어디서나 만들 수 있다, 고아 증발은 8~10% |
| 5 | **실제 제도를 핵심 메커닉으로 승격** | 원안에 없던 실제 규정이 원안보다 더 재미있는 경우가 많다: 한국 전통주 주세 감면 한도, 호주 소규모 증류소 환급 한도, 제주 지하수 취수 허가, 켄터키 배럴세 단계 폐지, 프랑스 DOM 럼 감면 쿼터, 중국 반덤핑(대형 하우스만 면제), 스웨덴 국영 독점 + 농장 직판 시범 |

**규모:** 원안 24개 + 기존 표준 산지 2개(경기·간토) = **26개 산지 / 15개 국가**, 선택 추가 1개(진먼). 엔진 의존도에 따라 3단계로 나눈다(§5).

| 단계 | 산지 | 필요한 엔진 작업 |
|---|---|---|
| **Tier 1** — 기존 주종·국가 | 경기·안동·제주 / 간토·오사카교토·홋카이도 / 이란(+진먼) | 산지 레이어, 증발 보정, 특성 레버, 부지 개량, 세제 특례, 채널 규칙 |
| **Tier 2** — 새 국가 + 기존 주종 | 아일라·스페이사이드·런던·더블린·태즈메이니아·고아·쓰촨·구이저우 | + 수출 시장 레이어, 3회 증류, 해풍 축, 백주 공정, 새 국가 세제·시장 데이터 |
| **Tier 3** — 새 주종 | 켄터키·마조비아·스코네·할리스코·오아하카·자메이카·바베이도스·마르티니크·꼬냑·가스코뉴·노르망디 | + 버번·보드카·럼·브랜디·아가베 주종 체인(원료·설비·스키마) |

> **가장 큰 반론:** 26개 산지 × 11개 신규 주종은 1인 개발 범위를 크게 넘는다. 산지가 늘수록 산지당 밸런스 깊이는 얕아진다. **Steam 1.0 출시 세트는 8~10개 산지로 제한하고 나머지는 업데이트로 돌리는 것을 권장**한다(§7).

## 1. 설계 원칙

| # | 원칙 | 적용 |
|---|---|---|
| R1 | **국가 = 법·세제·내수 시장, 산지 = 땅** | 세율·GI 표기·시장 규모·채널 규칙은 국가 데이터, 기후·물·원료 단가·고유 이벤트·생산 상한은 산지 데이터 |
| R2 | **모든 특성은 엔진 레버로 표현** | 문장("평론가가 좋아한다")이 아니라 보정치 키·필드 값으로 쓴다. 엔진에 없는 레버는 "신규"로 표시하고 §3 카탈로그에 모은다 |
| R3 | **확률은 결과가 아니라 정보에** (결정 #18) | 결과는 공정·기후의 결정론적 함수. 불확실성은 "샘플링 전에는 모른다"로 준다. 재해 이벤트의 발생 자체는 확률이지만 피해량은 대비 수준으로 정해진다 |
| R4 | **판을 끝내는 단일 리스크 금지** | 제재는 경고 → 벌금 → 일시 정지 → 영업 위기의 단계형. 큰 피해는 **대응 수단(부지 개량·보험·예보)이 있을 때만** 허용 |
| R5 | **보너스와 대가는 쌍으로** | 산지 = 정체성 1줄 + 보너스 2~4 + 페널티 2~4 + 고유 이벤트 1~3 + "자연스러운 전략"과 그 약점. 공짜 보너스 금지 |
| R6 | **지배 전략 문제와 연결** (PRD §15.2 #2) | v0.6 밸런스의 근본 원인은 "숙성 재고를 오래 묵히는 비용이 0"이라는 점이다. 산지 특성으로 **보유 비용**을 만든다: 열대 증발(이란·고아·카리브), 켄터키 배럴세·오버오크, 런던 외부 보관료, 일본 지진 |
| R7 | **대표 규정만** (결정 #24) | 실제 제도는 게임에 의미 있는 뼈대만 옮긴다. 현실을 부풀린 설정은 `[게임적 과장]`으로 남겨 나중에 사실과 헷갈리지 않게 한다 |
| R8 | **용어 통일** | "AOC"는 프랑스 원산지 통제 명칭이다. 게임 전체 용어는 **GI(지리적 표시)** 로 통일하고, 프랑스 산지 설명에서만 AOC를 쓴다 |

## 2. 데이터 구조와 기후 보정

### 2.1 국가 / 산지 분리 `[제안]`

```ts
interface CountryDef {
  id: CountryId;                 // KR JP TW UK IE US IN AU FR MX JM BB CN PL SE
  nameKo: string;
  tax: TaxDef;                   // 종가세·교육세·종량세·부가세 (기존 RegionDef.tax)
  taxRelief?: TaxReliefDef[];    // 신규: 한국 전통주 감면, 호주 소규모 환급, 미국 소규모 세율, 프랑스 DOM 럼 쿼터
  laborCost: number;
  retailMarkup: number;
  market: Record<ProductCategory, MarketDef>;
  categoryNames?: Partial<Record<ProductCategory, string>>;
  seasonality: number[];
  channels: ChannelRules;        // 신규: 온라인 직판 범위, 국영 독점 입찰, 면세 채널
  domesticSpiritPremium: number;
  bulkMarketDepth: number;
  sourcedPenalty: number;
  exportAccess?: Record<ExportMarketId, { tariff: number; logistics: number }>; // Tier 2
}

interface SiteDef {
  id: SiteId;
  countryId: CountryId;
  nameKo: string;
  difficulty: 1 | 2 | 3 | 4 | 5;
  tempC: number[]; humidity: number[];   // 월별, 남반구는 실제 달 그대로
  angelShareFactor: number;              // 신규: 기후 모델 증발 보정 (§2.2)
  water: 'soft' | 'medium' | 'hard' | 'peaty' | 'volcanic' | 'limestone' | 'glacial';
  allowedKinds: SpiritKind[];            // 국가 허용 주종의 부분집합
  overheadPerMonth: number;
  buildCostFactor: number;               // 신규: 설비·숙성고 건설비
  logistics: { inbound: number; outbound: number; export: number }; // 신규
  ingredientPrice: Record<string, number>;                  // 신규(기존 priceIndex에 곱)
  caskPriceFactor: Partial<Record<CaskTypeId, number>>;      // 기존
  eventWeights: Partial<Record<EventCategory, number>>;     // 기존(산지로 이동)
  productionCalendar?: { kinds: SpiritKind[]; months: number[] }[]; // 신규
  capacityCap?: CapacityCapDef;          // 신규: 취수 허가·보호 산지·장인 등급
  terroir?: { axis: AxisId; perMonth: number; cap: number; when: TerroirCondition }[]; // 신규
  upgrades?: SiteUpgradeId[];            // 이 산지에서 의미가 큰 부지 개량 (§3.2)
}
```

- **이행:** 지금의 `REGIONS.KR / JP / TW`는 그대로 `CountryDef` + 표준 산지(경기·간토·이란)로 쪼갠다. 기존 세이브의 `regionId`는 표준 산지로 마이그레이션한다
- 이벤트의 `regions` 필드는 `countries` / `sites` 두 갈래로 확장한다 (지진 = 일본 전체, 페리 결항 = 아일라만)

### 2.3 오버오크는 주사위가 아니라 모델에서 나온다

| **켄터키 상층(+3°C, 습도 45%) · 새 탄화 오크** | 34 | 56 | **81** | **91** | **67.6%** |
| 이란 · ex-버번 | 27 | 47 | 72 | 85 | 54.7% |

- 버번 카테고리의 탄닌 상한을 70으로 두면, 상층 새 오크는 **약 7년부터 결정론적으로 오버오크**가 된다 → 원안의 "10년 이상 숙성 시 망작 확률 30%"를 대체한다. 플레이어는 **랙 층 순환(로테이션)** 이나 이른 병입으로 관리한다
- 상층 랙의 도수 상승(62.5% → 67.6%)도 실제 켄터키 현상과 방향이 맞는다
- 참고: 엔진은 한 번 채운 캐스크의 활성도가 숙성 중에 줄지 않아 탄닌이 계속 오른다. 장기 숙성 밸런스를 볼 때 "활성도의 시간 감쇠" 도입을 함께 검토할 것 `[튜닝]`

### 4.1 한국

**국가 공통:** 종가세 72% + 교육세(주세의 30%) + 부가세 10% (기존). 내수 시장·B2B 깊이 0.8·국산 원액 프리미엄 +25%·매입 원액 감점 15% (기존).

- **기준판매비율 `[결정 #61]` — 적용, 단 고세율 시장으로 보정:** 국산 종가세 주류는 유통 이윤이 붙은 출고가에, 수입 주류는 그 전의 수입 신고가에 과세돼 국산이 불리했다. 이를 줄이려고 2024년부터 국산 주류 과세표준(출고가)에서 주종별 기준판매비율만큼을 빼고 주세를 매긴다. 국세청 고시 제2026-23호: **소주 23.2%, 위스키 28.0%, 일반증류주 21.3%, 리큐르 22.7%, 브랜디 11.2%** (2024년 최초: 22.0%·23.9%·19.7%·20.9%·8.0%). 게임 매핑: 증류식 소주 = 소주, 몰트·그레인·블렌디드 = 위스키, 진·고량주·3년 미만 곡물 스피릿·기타 증류주 = 일반증류주. 실효 주세율은 소주 약 55%, 위스키 약 52%(기존 72%)
  - 효과: 같은 소비자가 기준 권장 출고가가 진 +11.5%, 소주 +12~14%, 위스키 +16% → 국산 생산자 마진 증가
  - 보정 없이 켜면 한국 10년 순자산이 약 2배가 된다(§6.1) → 오너 결정: "높은 주세로 마진이 얇고, 가격이 오른 만큼 소비자가 구매를 꺼리는" 방향으로 보정
  - **수입 경쟁 기준가:** 기준판매비율로 생긴 출고가 여유를 기준 소비자가에서 되돌린다 — 위스키 ×0.865, 소주 ×0.888, 일반증류주 ×0.897 (`krImportCompetitionFactor`). 수입 주류는 여전히 유통 이윤이 빠진 신고가에 과세돼 매대 가격이 낮다는 해석. 결과: 권장 출고가는 v0.6과 같고 소비자가만 내려간다
  - **가격 민감도:** 한국 전 카테고리 가격 탄력성 +0.2 — 기준가보다 비싸게 매기면 v0.6보다 더 많이 안 팔린다
  - 결과(위스키 4년 700ml 46%, 권장가): 출고가 58,100원 / 소비자가 144,423원 → **생산자 몫 40%·주세 27%** (일본: 출고가 72,700원 / 소비자가 108,105원 → 생산자 몫 67%·주세 3%)
  - 스위치: `src/sim/content/regions.ts`의 `APPLY_KR_BASE_DEDUCTION`·`setKrBaseDeduction()`. 밸런스 비교: `KR_DEDUCTION=off npm run balance -- 20 120 all gyeonggi` (v0.6 체계)
- **전통주 특례 (신규 `taxRelief` + `channels`):** 민속주·지역특산주는 ① 전년 출고 **500kL 이하**(증류주)면 감면 자격, 처음 **100kL는 주세 50%, 100~200kL는 30%** 감면(2025년 개정) ② **온라인 직판 허용**(일반 위스키·증류주는 택배 판매 불가, 스마트오더 픽업만). 자격 `[결정 #62]` = **주원료가 모두 산지가 정한 지역 농산물**(발효제 누룩은 허용, 주종 무관) — 안동은 안동 쌀만, 제주는 제주 차조 50% 이상 + 나머지 국산 쌀. 수입 맥아·옥수수·주정이나 타지역 원료가 하나라도 들어가면 자격 없음. 경기의 "농업법인 설립" 경로는 v0.8 미구현

  3. **고에스테르 B2B:** 유럽 블렌더·향료 회사가 고에스테르 원액을 고가 매입 — 역사적으로 독일 럼 페어슈니트(Rum-Verschnitt) 용 '컨티넨털' 럼 수요
  4. 헤비 단식 럼 매니아 매력도 ×1.3
- **페널티**
  1. **산패 관리:** 발효 기간·`funk` 목표가 높을수록 탱크 원액 `acetic` 기대 상승량↑, 디스틸러 스탯이 낮으면 더 커진다. QC가 감지 → 재증류(비용·손실 20%)로 회수 (원안 "발효액 통째로 폐기" → 결정론적 기대값 + 감지는 정보 + 회수 수단)
  2. **허리케인:** 카리브 3곳 중 가장 높은 가중 (2025년 10월 5등급 허리케인이 자메이카 남서부에 상륙해 주요 증류소가 큰 피해를 입었다) — 8~10월, 생산 중단 1~3개월 + 캐스크 손실, 예보 제공
  3. 증발 연 7%
- **자연 전략 → 약점:** 고에스테르 원액 B2B로 현금 + 장기 숙성 펑키 럼. 산패 관리가 직원 역량에 달렸다

## 6. 밸런스 검증 계획

- **스크립트:** `npm run balance -- 20 120 all <산지>`로 확장. 산지별 전략 풀에 산지 고유 전략을 추가한다 — 소규모 특례형(안동·태즈메이니아), 면세 채널형(제주), 원액 납품형(꼬냑·쓰촨), 즉시 판매형(할리스코·가스코뉴·마르티니크·마조비아)
- **통과 기준**
  1. 산지 안에서 한 전략이 60% 이상 1위면 실패 (결정 #37)

**해석**

1. **나라별 최적 전략은 유지된다** — 한국 = 브랜드형, 일본·대만 = 혼합형 (결정 #36 충족)
2. **같은 나라 안에서 산지는 수익 수준·위험 성격을 바꾸지만 1위 전략은 바꾸지 못한다.** 제주는 그레인형을 막고(취수 상한, 20/20 전멸), 홋카이도는 흑자가 가장 늦지만 장기 순자산이 가장 높고, 이란은 증발로 장기 보유 가치가 떨어져 브랜드형 1위가 1회 → 4회로 늘었다. 그래도 **7개 산지 모두 한 전략이 60% 이상 1위** → 지배 전략 문제(PRD §15.2 #2)는 산지 레이어만으로 풀리지 않는다. 다음 레버는 전 지역 공통의 숙성 재고 보유 비용(보관료·보험료, §15.2 #2 ①)
3. **안동은 실제 감면 한도로는 너무 쉽다** — 게임 속 소주 생산량(연 약 11kL)은 실제 감면 한도(100kL)의 약 1/10이라 "작게 남을 것인가" 갈림길이 생기지 않는다. 선택지: ① 그대로(안동 = 쉬운 산지 ★2) ② 감면 구간을 게임 규모로 축소(예: 연 10kL까지 50%·20kL까지 30%, 전년 50kL 초과 시 자격 상실) ③ 수출 레이어(Tier 2)에서 안동의 "해외 인지도 0" 페널티가 들어오면 다시 보기
4. **대만은 가장 어려운 나라가 됐다** (v0.6 17.0억 → 8.8억). 연 10% 증발(카발란 보고치)의 결과다. 의도한 "빠른 숙성 + 장기 보유 불리" 방향은 맞지만 낙차가 커서 오너 확인 필요
