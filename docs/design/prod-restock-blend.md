# 재고 보충 — 조건을 골라 블렌더가 채운다 `[제안 P-PROD-77]` (PROD, 2026-11-27)

## 1. 자동 납품 `autoRestockSource`와 견줘 `[사실]`

| | 자동 납품(#399 · #419) | 오너 물음(손 보충 한 번) |
|---|---|---|
| 언제 | 매달 결산에서 저절로 | 플레이어가 누를 때 한 번 |
| 숙성 최저 | `months`(통 하한) | 같은 뜻 |
| 숙성 상한 | `maxMonths` | 같은 뜻 |
| 품질 | `minKnownQuality`(샘플 기록 하한) | 같은 뜻 |
| 통 종류 | `caskTypes` | 없음 — 필요하면 넣을 수 있다 |
| **향미 방향** | **없다** — 어린 통부터 순서대로 쓴다 | **새로운 것** — 블렌딩 테이블 「○○ 위주 / 밸런스」 |
| 섞는 비율 | 없다(쓸 순서대로 채움) | 블렌더가 정한다(`delegatePlan` — 샘플 기록 육각형으로 최적화) |
| 보호 | 보호 태그 · 플래그십 예비(#260) · 띠 정책(#380 · #399) · 같은 레시피(#293) · 같은 스타일(#422) | 지금 손 보충은 아무 통이나 고를 수 있다 — **자동 고르기는 자동 납품과 같은 보호를 써야 한다**(2절) |

- **겹치는 것:** 숙성 최저 · 상한 · 품질 하한은 같은 뜻이다. 화면 문구와 걸러내기를 그대로 빌려 쓸 수 있다.
- **새로운 것:** 향미 방향, 그리고 비율을 블렌더가 정하는 것이다. 자동 납품은 비율 없이 어린 통부터 채운다.

## 2. 판 도중 최소형 — 「블렌더에게 맡겨 채우기」(화면만)

**보이는 것:** 「기존 제품 재고 보충」 → 「보충할 제품」을 고르면, 그 아래에 접힌 묶음이 하나 생긴다.
- **조건:** 숙성 최저 · 상한(년) · 품질 하한(아는 품질) · 향미 방향(블렌딩 테이블과 같은 7가지 — 여섯 축 「○○ 위주」 + 밸런스) · 병 수
- **미리보기:** 쓸 통 n개 · 예상 품질(추정 ±) · 표기 연수 · 「예상보다 ○○」 — 블렌딩 테이블의 두 번 누름 확인(`delegateCheck`)과 같다
- **실행:** `delegateBlend { player: { focus, minMonths, maxMonths }, options: { …제품과 같은 병 · 도수 · 포장, restockId } }` — 이미 있는 행동이다

**통 후보 거르기(화면 · 읽기만):**

| 거름 | 기준 | 까닭 |
|---|---|---|
| 같은 원액 종류 | 제품 범주(몰트 · 그레인 · 블렌디드는 몰트 + 그레인) | 범주가 다르면 보충 행동이 거절한다(`restockChecks`) |
| 같은 피니시 | 제품 피니시와 같은 통만 | 다르면 보충 행동이 거절한다 |
| 표기 연수 | **숙성 최저의 기본값 = 제품 표기 연수.** 그보다 낮추면 「표기가 n년 → m년으로 내려간다」를 미리보기에 띄운다 | 가장 어린 통이 표기를 정한다. 지금 보충은 경고만 하고 막지 않는다 |
| 보호 통 | 보호 태그 · 플래그십 예비는 뺀다(`autoRestockExcluded`와 같다) | 12년 후보를 보충에 써 버리는 사고를 막는다(#260) |
| 띠 정책 | 판매 탭의 연령 띠 정책을 지킨다(`agePolicyFilter`와 같다) | 자동 납품과 같은 약속(#380 · #399) |
| 같은 레시피 · 스타일 | **기본으로 켠다** · 끌 수 있다 | 자동 납품(#293 · #422)과 같다. 손 보충은 원래 자유라 끌 수 있게 둔다 |
| 품질 하한 | 샘플 기록이 하한 이상인 통만 · 기록 없는 통은 뺀다 | #419와 같다. 블렌더도 맛본 통만 섞는다(#157) |

**봇 · 세이브:** `[사실]` 새 행동 · 새 필드가 없다. 봇(X0 · balance)은 `delegateBlend`를 부르지 않으므로 출력이 바이트 그대로일 것이다 — PR에서 바이트 대조로 확인한다.

**크기 `[추정]`:** 화면 1 PR이다.
- PROD 잎 함수(통 후보 거르기)
- Bottling 묶음 하나
- 시험: 거름마다 하나 · 행동과 미리보기가 같은지

**리스크 · 반론:**
- **블렌더 실력에 기댄다.** 마스터 블렌더가 없으면 대표가 직접 읽어 오차가 크다. 「예상보다 ○○」가 크게 빗나갈 수 있다. 블렌딩 테이블과 같은 성질이라 새 위험은 아니다.
- **「품질」은 고를 수 있어도 「높이는」 것은 아니다.** `delegatePlan`은 향미 거리만 줄인다. 품질은 하한으로 거를 뿐이다. 오너가 「품질 높은 쪽으로 섞어 달라」를 뜻했다면 그것은 새 규칙이다(3절).
- **화면이 길어진다.** 보충 칸에 이미 품질 예상 · 재고 적체 · 자동 납품 안내가 있다. 그래서 묶음은 접어 둔다.
- **반론 — 굳이 지금?** 블렌딩 테이블 「내 조건」으로 새 제품을 내는 길은 이미 있다. 판 도중에는 「블렌딩 테이블에 보충할 제품 고르기 한 칸」만 더하는 더 작은 판도 된다. 다만 보호 · 띠 정책 거르기가 없어 12년 후보를 쓸 위험이 있다. 그래서 권장은 위 최소형이다.

## 3. 판 뒤 온전한 형 — 조건을 제품에 기억

- 손 보충은 그 조건을 미리 채워 보인다.
- **자동 납품도 같은 조건으로 블렌더가 비율을 정해 채운다.** 지금 자동 납품은 어린 통부터 채운다.
