## 0. 한 줄 결론

감사가 가리키는 최신 요구(승리 = 자가 증류 싱글 몰트의 최초 유상 판매 · 참값 비공개 유지 · 배치 계보 · 3종 가치평가 · 6영역 난이도 · 수출/상세 HR 1.0 이관)는 **저장소의 오너 확정 결정 #133·#141·#145·#146·#166·#167·#215·#232·#263과 정면으로 충돌**한다. 저장소 결정은 모두 오너가 이 공정에서 확정한 것이고, CORE 쪽은 직접 문답 3개(107·108·109)만 원문이 있다. 그래서 이 문서는 **(1) 무엇이 충돌하는지, (2) 채택하면 무엇을 어떻게 바꾸는지, (3) 어느 묶음을 지금 동결할 수 있는지**를 적고, **오너가 2026-11-13 "모두 권장안대로"로 채택했다(결정 #308~#315). §10의 권장안이 그대로 결정이다.**

## 2. 캠페인 목표 — RuleSet의 한 값으로 `[결정 #308·#309]`

### 2.1 세 안을 나란히 — **(다) 채택**(#308 사건 구조 + #309 A = 144). (가)는 고친 결정, (나)는 채택하지 않음

| | **(가) 현행 — 저장소 확정** #133·#141·#145·#263 | **(나) 감사 통합안** A02·A03 (CORE-73·79·84·105 — 간접 확인) | **(다) 12년 유상 출하 — 검토안** (README §11) |
|---|---|---|---|
| 승리 자격 | 생존 + 순자산 ≥ 자기자본 × 3 (플래그십은 등급 요소) | 자체 증류·같은 증류소·싱글 몰트·구성 원액 모두 **목재 숙성 ≥ 180개월**인 제품의 **최초 정상 유상 판매** | 같은 자격, **≥ 144개월**, 사건은 정상 거래에 따른 **출고** |
| 판정 시점 | 180개월째(또는 종료) **한 번** | 적격 거래가 생기면 그때. 180개월 강제 판정 **폐지**, 미판매면 running | 같음(144개월·180개월 강제 종료 없음) |
| 순자산 | 승리 조건 | **성과 지표**(등급)로 분리 | 같음 |
| 코드 | `judgeGoal`·`flagshipMinMonths = 144` | `campaignGoal.minOakMonths = 180` + 적격성 함수 + 판매 사건 | `campaignGoal.minOakMonths = 144` + 같은 함수·사건 |
| 바꾸는 저장소 결정 | — | #133·#141·#145·#263(승리) · #186(보충 때 어린 원액 기준은 유지되나 판정은 로트 기준) | 같음 |

- **PM 읽기:** (나)와 (다)는 **구조 작업이 같고 매개변수 A와 테스트 경계(179/180 ↔ 143/144)만 다르다.** 그래서 결정을 둘로 나눌 수 있다 — **77a** 승리 "사건" 구조(유상 출하 사건·자가 몰트 자격·순자산 분리·강제 판정 폐지)를 채택할지 · **77b** 연수 A(180/144). 77a가 채택되면 F1~F3(§8)은 77b 전에 동결·구현할 수 있다.
- **PM 권장안(반론과 함께):** 77a 채택 · 77b는 **(다) 144개월**. 근거 — 기존 144 자산(플래그십 예비 통 #260·후보 안내·중반 목표·P8 CALIB)을 그대로 쓰고, 측정 창 180개월(#277 F-MVP)이 유효하며, 후반 36개월 공백 위험이 작다. **반론** — 15년은 직접 문답 107·108·109의 전제이고 헤리티지 서사(#133 "15년이 가장 짧으면서도 서사가 완성되는 길이")가 강하다. 12년은 오너의 질문이지 지시가 아니다. 어느 쪽이든 **구순자산 성공률(micro 70~90 · standard 40~60)은 새 승리의 합격선으로 재사용하지 않는다**(README §9).

### 2.2 유상 판매(출하)의 운영 정의 — 감사 통합안

**실물 출고 + 양의 대가가 확정된 정상 매출 거래.** 현금 또는 정상 확정 매출채권(`finance.receivables`) 인정. 제외: 무료 샘플·폐기·자기거래·예약 선수금만의 수령·단순 병입·창고 이동. 적격성은 **거래 시점의 출고 로트** 기준으로 고정한다. 법률·회계 주장이 아니라 게임 판정 계약이다.
